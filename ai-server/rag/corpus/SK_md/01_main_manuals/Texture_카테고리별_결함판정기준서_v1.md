# Texture 카테고리별 결함판정기준서

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 사용하는 MVTec AD texture 5개 카테고리의 결함 판정 기준과 작업자 점검 절차를 설명하기 위한 문서이다.

본 프로젝트는 이미지 기반 이상탐지 모델을 통해 제품 표면의 정상/이상 여부를 판단하고, anomaly score, 판정 결과, heatmap 또는 anomaly map을 제공한다. 작업자와 관리자가 texture 카테고리별 결과를 해석하려면 각 카테고리의 표면 패턴, 주요 결함 유형, 재검사 조건, 불량 의심 조건을 구체적으로 이해해야 한다.

이 문서는 `Texture_계열_결함해석가이드_v1`에서 설명한 공통 해석 관점을 바탕으로, carpet, grid, leather, tile, wood 각각에 대한 상세 판정 기준과 점검 절차를 제공한다. RAG 기반 문서 질의응답, 결과 상세 설명, 작업자 대응 절차 추천의 근거 문서로 사용한다.

| 항목 | 내용 |

본 문서는 MVTec AD texture 5개 카테고리를 모두 포함한다. 계열 공통 해석 기준은 별도 문서인 `Texture_계열_결함해석가이드_v1`에서 다루며, 본 문서는 카테고리별 상세 판정 기준과 점검 절차에 초점을 둔다.

## 3. 카테고리별 판정 기준 개요

Texture 카테고리는 표면 패턴, 반복 무늬, 질감, 색상 변화, 국소 손상 여부를 중심으로 판정한다. 카테고리별로 결함이 나타나는 형태와 오탐 원인이 다르므로, 동일한 anomaly score와 heatmap 형태라도 표면 특성에 맞게 해석해야 한다.

| 카테고리 | 핵심 판정 관점 | 주요 결함 유형 | 주요 오탐 요인 |
| --- | --- | --- | --- |
| carpet | 반복 패턴, 섬유 결, 얼룩, 국소 손상 | 패턴 깨짐, 오염, 얼룩, 국소 손상 | 섬유 질감 차이, 그림자, 정렬 차이 |
| grid | 격자 반복 구조, 선 연속성, 교차점 | 격자선 끊김, 패턴 깨짐, 국소 결함 | 정렬 차이, 초점 흐림, 배경/그림자 |
| leather | 표면 질감, 주름, 스크래치, 색상 변화 | 스크래치, 오염, 질감 변화, 찍힘 | 자연스러운 질감 변화, 조명 반사 |
| tile | 표면 균열, 파손, 오염, 모서리/경계 | 균열, 표면 파손, 오염, 얼룩, 색상 변화 | 조명 반사, 경계 오탐, 그림자 |
| wood | 나뭇결 연속성, 스크래치, 찍힘, 색상 변화 | 스크래치, 찍힘, 결 변화, 오염, 색상 변화 | 자연스러운 나뭇결 차이, 조명 방향 |

## 4. 공통 판정 흐름

카테고리별 세부 기준은 다르지만, texture 계열 결과를 확인할 때는 다음 흐름을 기본으로 적용한다.

1. 검사 카테고리와 입력 이미지가 올바른지 확인한다.

2. anomaly score와 정상/재검사/불량 의심 판정 결과를 확인한다.

3. 원본 이미지를 열어 표면 패턴, 질감, 색상 변화를 확인한다.

4. heatmap 또는 anomaly map이 집중된 위치와 형태를 확인한다.

## 5. 카테고리별 우선 확인 위치와 결함 유형을 비교한다.

## 6. 조명 반사, 그림자, 초점 흐림, 촬영 위치 변화 등 오탐 요인을 확인한다.

## 7. 필요한 경우 동일 조건에서 재촬영한다.

## 8. 재검사 또는 반복 촬영에서도 동일 위치에 heatmap이 반복되면 반복 감지 추가 상태로 기록하고, 후속 확인 또는 불량 의심 대상으로 등록한다.

## 9. 최종 확인 내용과 조치 결과를 기록한다.

## 5. 카테고리별 상세 판정 기준

### 5.1 carpet

carpet 카테고리는 반복 패턴, 섬유 결, 표면 얼룩, 국소 손상 여부를 중심으로 확인한다. Heatmap이 반복 패턴이 끊긴 위치나 얼룩 부위에 집중되면 패턴 깨짐, 오염, 표면 손상 가능성을 우선 검토한다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 섬유 질감과 반복 패턴이 중요하며, 정상 샘플 사이에도 질감 차이가 존재할 수 있다. |
| 주요 결함 유형 | 패턴 깨짐, 오염, 얼룩, 국소 손상, 작은 점 결함 |
| 우선 확인 위치 | 반복 패턴이 끊긴 위치, 얼룩 부위, 표면 국소 영역 |
| 재검사 조건 | heatmap이 넓게 퍼지거나 섬유 질감 차이와 실제 결함이 구분되지 않는 경우 |
| 불량 의심 조건 | 패턴 깨짐 또는 오염 위치에 heatmap이 반복 집중되고 원본에서 표면 이상이 확인되는 경우 |
| 오탐 가능 원인 | 섬유 질감의 자연스러운 변화, 그림자, 조명 방향, 정렬 차이 |
| 작업자 점검 | 정상 carpet 샘플과 패턴 연속성, 얼룩 위치, 표면 국소 손상 여부를 비교한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 반복 패턴 부위 | 패턴 깨짐 또는 정렬 차이 가능성 | 주변 패턴 연속성 비교 |
| 얼룩 부위 | 오염, 색상 변화, 그림자 가능성 | 원본 확대 및 조명 조건 확인 |
| 작은 점 형태 | 국소 손상, 먼지, 작은 이물 가능성 | 원본 이미지 확대 확인 |
| 넓은 표면 영역 | 섬유 질감 차이 또는 촬영 조건 영향 | 정상 샘플과 재촬영 비교 |

### 5.2 grid

grid 카테고리는 격자 반복 구조, 선의 연속성, 교차점, 미세 결함 여부를 중심으로 확인한다. Heatmap이 격자선이 끊긴 위치나 교차점에 집중되면 패턴 깨짐 또는 국소 결함 가능성을 우선 검토한다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 규칙적인 격자 구조와 선의 연속성이 판정에 중요하다. |
| 주요 결함 유형 | 격자선 끊김, 패턴 깨짐, 국소 결함, 작은 점 결함 |
| 우선 확인 위치 | 격자 교차점, 선이 끊긴 위치, 반복 패턴이 어긋난 영역 |
| 재검사 조건 | 작은 heatmap이 나타나지만 원본에서 선 끊김이 명확하지 않은 경우 |
| 불량 의심 조건 | 격자선 끊김 또는 패턴 깨짐 위치에 heatmap이 반복 집중되는 경우 |
| 오탐 가능 원인 | 이미지 정렬 차이, 초점 흐림, 그림자, 미세 배경 변화 |
| 작업자 점검 | 격자선 연속성과 교차점 주변의 실제 끊김 여부를 원본 확대 이미지로 확인한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 격자선 위 | 선 끊김, 패턴 깨짐 가능성 | 선 연속성 확인 |
| 교차점 | 국소 결함 또는 정렬 오차 가능성 | 교차점 주변 확대 확인 |
| 반복 패턴 일부 | 패턴 어긋남 또는 오탐 가능성 | 주변 반복 구조와 비교 |
| 넓은 영역 | 초점 흐림 또는 조명 영향 가능성 | 촬영 조건 확인 후 재촬영 |

### 5.3 leather

leather 카테고리는 표면 질감, 주름, 스크래치, 색상 변화, 국소 오염을 중심으로 확인한다. 얇은 선 형태 heatmap은 스크래치 가능성을 의미할 수 있으며, 넓게 퍼진 heatmap은 조명 반사나 정상 질감 변화일 수 있다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 표면 질감과 광택 변화가 크므로 정상 질감 변화와 실제 결함을 구분해야 한다. |
| 주요 결함 유형 | 스크래치, 오염, 질감 변화, 찍힘, 색상 변화 |
| 우선 확인 위치 | 선형 손상 위치, 색상 변화 부위, 질감이 갑자기 달라진 영역 |
| 재검사 조건 | heatmap이 넓게 퍼지거나 질감 변화인지 실제 결함인지 불명확한 경우 |
| 불량 의심 조건 | 얇은 선 형태 heatmap이 동일 위치에 반복되고 원본에서 스크래치가 확인되는 경우 |
| 오탐 가능 원인 | 광택 변화, 주름, 조명 반사, 정상 질감 차이 |
| 작업자 점검 | 정상 leather 샘플과 표면 결, 광택, 색상 차이를 비교하고 선형 손상을 확대 확인한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 얇은 선 영역 | 스크래치 또는 주름 가능성 | 선형 손상 여부 확인 |
| 색상 변화 부위 | 오염, 변색, 조명 영향 가능성 | 원본 확대 및 조명 상태 확인 |
| 넓은 표면 영역 | 광택 변화 또는 조명 반사 가능성 | 촬영 조건 확인 후 재촬영 |
| 작은 점 형태 | 찍힘, 먼지, 국소 오염 가능성 | 원본 이미지 확대 확인 |

### 5.4 tile

tile 카테고리는 표면 균열, 파손, 오염, 색상 변화, 모서리 또는 경계 부위를 중심으로 확인한다. Heatmap이 길고 얇은 선 형태로 나타나면 균열 가능성을 우선 확인한다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 표면이 비교적 평탄하며 균열, 파손, 얼룩, 모서리 결함이 판정에 중요하다. |
| 주요 결함 유형 | 균열, 표면 파손, 오염, 얼룩, 색상 변화 |
| 우선 확인 위치 | 균열선, 모서리, 표면 국소 영역, 색상 변화 부위 |
| 재검사 조건 | 선형 heatmap이 약하게 나타나지만 원본에서 균열이 명확하지 않은 경우 |
| 불량 의심 조건 | 균열선, 파손 위치, 모서리 손상에 heatmap이 반복 집중되는 경우 |
| 오탐 가능 원인 | 조명 반사, 경계 오탐, 그림자, 표면 색상 편차 |
| 작업자 점검 | 원본 이미지를 확대하여 균열선, 모서리 손상, 오염 여부를 확인한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 긴 선 형태 | 균열 또는 스크래치 가능성 | 선형 손상 여부 확인 |
| 모서리/경계 | 표면 파손 또는 경계 오탐 가능성 | 정상 샘플과 모서리 비교 |
| 표면 국소점 | 오염, 찍힘, 작은 파손 가능성 | 원본 확대 확인 |
| 넓은 표면 영역 | 조명 반사 또는 색상 변화 가능성 | 조명 상태 확인 후 재촬영 |

### 5.5 wood

wood 카테고리는 나뭇결의 연속성, 스크래치, 찍힘, 색상 변화 여부를 중심으로 확인한다. 나뭇결은 정상 상태에서도 자연스러운 변화가 있으므로, 결 방향과 다른 선형 손상 또는 국소 강한 heatmap을 우선 확인한다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 나뭇결과 색상 변화가 자연스럽게 존재하므로 정상 패턴과 결함을 구분해야 한다. |
| 주요 결함 유형 | 스크래치, 찍힘, 결 변화, 오염, 색상 변화 |
| 우선 확인 위치 | 나뭇결이 끊긴 위치, 선형 손상 부위, 국소 찍힘 영역 |
| 재검사 조건 | heatmap이 나뭇결을 따라 넓게 퍼지거나 정상 결 변화와 구분되지 않는 경우 |
| 불량 의심 조건 | 나뭇결 방향과 다른 선형 손상 또는 국소 찍힘 위치에 heatmap이 반복 집중되는 경우 |
| 오탐 가능 원인 | 자연스러운 나뭇결 차이, 조명 방향, 색상 편차, 그림자 |
| 작업자 점검 | 정상 wood 샘플과 결 방향, 색상, 국소 손상 위치를 비교한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 나뭇결 끊김 위치 | 결 변화 또는 손상 가능성 | 주변 나뭇결 연속성 확인 |
| 얇은 선 영역 | 스크래치 가능성 | 선형 손상 여부 확인 |
| 국소 점 영역 | 찍힘, 오염, 작은 결함 가능성 | 원본 확대 확인 |
| 넓은 결 방향 영역 | 정상 나뭇결 또는 조명 영향 가능성 | 정상 샘플과 재촬영 비교 |

## 6. 재검사 및 불량 의심 조건

### 6.1 기본 판정 기준

카테고리별 판단 기준과 별개로, 다음 조건은 texture 계열 전체에서 재검사 또는 불량 의심 판단에 참고한다. 정확한 threshold 값은 모델 버전, 카테고리, 검증 데이터에 따라 달라지므로 본 문서에서 숫자로 고정하지 않는다.

| 구분 | 조건 | 작업자 조치 |
| --- | --- | --- |
| 정상 처리 가능 | score가 낮고 heatmap이 약하거나 원본에서 결함이 보이지 않음 | 정상 처리 가능. 단, 반복 이력은 결과 화면에서 확인한다. |
| 재검사 권장 | score가 중간이거나 얇은 선/작은 점 heatmap이 있으나 원본 결함이 불명확함 | 동일 조건으로 재촬영하고 정상 texture 샘플과 비교한다. |
| 불량 의심 | score가 높고 카테고리별 결함 위치에 heatmap이 명확하게 집중됨 | 후속 확인 또는 불량 의심 대상으로 등록한다. |

Texture 계열은 작은 표면 결함과 촬영 조건 변화가 유사한 heatmap 형태로 나타날 수 있으므로, 단일 결과보다 원본 이미지, 정상 샘플, 재촬영 결과를 함께 비교하는 것이 중요하다.

불량 의심은 자동 확정 불량을 의미하지 않는다. 작업자는 원본 이미지, heatmap 위치, 재검사 결과를 함께 확인한 뒤 후속 확인 또는 불량 의심 등록 여부를 결정한다.

본 문서에서 사용하는 score 낮음/중간/높음, heatmap 약함/국소 집중/넓게 분산 등의 표현은 모델 실험 결과 확정 전 사용하는 정성적 해석 표현이다. 실제 운영 단계의 threshold 및 정량 기준은 모델 버전, 카테고리별 검증 결과에 따라 별도 설정하며, 자세한 기준은 `Heatmap_AnomalyMap_해석가이드_v1` 및 `정상_재검사_불량_판정기준서_v1`에서 다룬다.

### 6.2 추가 상태/사유

| 추가 상태/사유 | 의미 | 작업자 조치 |
| --- | --- | --- |
| 저신뢰 | heatmap이 넓게 퍼지거나 조명/초점/위치 변화가 의심됨 | 설비 상태 확인 후 재촬영한다. |
| 반복 감지 | 재검사에서도 동일 위치에 heatmap이 반복됨 | 실제 결함 가능성이 높으므로 결과 기록 및 후속 확인을 수행한다. |
| 촬영 조건 의심 | 조명 반사, 초점 흐림, 위치 변화, 배경 변화가 결과에 영향을 준 것으로 보임 | 촬영 조건을 조정한 뒤 동일 조건으로 재촬영한다. |

## 7. 오탐 및 미탐 방지 유의사항

Texture 계열은 조명 방향이나 표면 반사에 따라 heatmap이 넓게 나타날 수 있다.

반복 패턴이 있는 carpet, grid는 작은 정렬 차이만으로도 패턴 깨짐처럼 보일 수 있다.

leather, wood처럼 자연스러운 질감 변화가 있는 표면은 정상 변형과 실제 결함을 구분해야 한다.

tile은 모서리나 경계 부근에서 경계 오탐이 나타날 수 있으므로 원본과 정상 샘플을 비교해야 한다.

작은 국소 heatmap은 실제 결함일 수 있지만 먼지, 압축 노이즈, 초점 문제일 수도 있다.

문서에 없는 원인은 단정하지 않고 원본 이미지, heatmap, 재검사 결과를 함께 확인한다.

미세 스크래치, 얇은 균열, 작은 점 결함은 해상도나 초점 상태가 낮으면 heatmap이 약하게 나타나 미탐될 수 있다.

score가 낮더라도 원본 이미지에서 명확한 선형 손상이나 반복 패턴 끊김이 보이면 재검사 또는 후속 확인을 요청한다.

## 9. 관리자 참고: 카테고리별 성능 해석

관리자는 모델 실험에서 texture 평균 성능을 계산하는 경우, 본 프로젝트의 texture 평균을 MVTec AD texture 5개 카테고리 기준으로 해석한다. 카테고리별 성능 편차가 클 수 있으므로 전체 평균만으로 모델을 판단하지 않고, category별 Image-level AUROC, Pixel-level AUROC, PRO, F1-score를 함께 확인한다.

| 지표 | 카테고리별 해석 기준 |
| --- | --- |
| Image-level AUROC | 각 texture 카테고리에서 정상/이상 이미지를 얼마나 잘 구분하는지 확인한다. |
| Pixel-level AUROC | 카테고리별 heatmap이 실제 결함 위치를 얼마나 잘 가리키는지 확인한다. |
| PRO | 결함 영역 단위로 위치 탐지 품질을 확인한다. 작은 국소 결함과 선형 결함이 많은 카테고리에서 중요하다. |
| F1-score | threshold 적용 후 정상/불량 의심 판정 균형을 확인한다. 오탐/미탐 조정에 활용한다. |
| Worst Category 또는 최저 성능 카테고리 | 선택 지표로 사용하며, 가장 성능이 낮은 texture 카테고리를 확인하여 운영 리스크를 판단한다. |
