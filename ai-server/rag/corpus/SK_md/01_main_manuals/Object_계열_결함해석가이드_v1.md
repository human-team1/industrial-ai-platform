# Object 계열 결함해석가이드

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 사용하는 MVTec AD object 계열 카테고리의 결함 해석 기준을 설명하기 위한 문서이다.

본 프로젝트는 이미지 기반 이상탐지 모델을 통해 제품의 정상/이상 여부를 판단하고, anomaly score, 판정 결과, heatmap 또는 anomaly map을 제공한다. 작업자와 관리자가 object 계열 결과를 해석하려면 각 카테고리의 구조적 특징, 주요 이상 유형, heatmap 집중 위치의 의미를 이해해야 한다.

이 문서는 object 계열의 공통 결함 해석 기준과 프로젝트에서 사용하는 object 5개 카테고리의 요약 해석 관점을 제공한다.
카테고리별 상세 판정 기준과 세부 점검 절차는 별도 문서인 `Object_카테고리별_결함판정기준서_v1`에서 다룬다.

## 3. Object 계열 결함 해석 개요

Object 계열은 제품의 전체 형태, 외곽 구조, 연결 상태, 구멍 주변 구조, 표면 손상 여부가 중요한 카테고리이다. Texture 계열이 표면 패턴과 질감 변화를 중심으로 해석되는 것과 달리, object 계열은 정상 제품의 구조와 비교하여 형태적 차이를 확인하는 것이 핵심이다.

| 해석 관점 | 설명 | 작업자 확인 포인트 |
| --- | --- | --- |
| 전체 형태 | 제품의 외곽 모양이나 크기가 정상과 다른지 확인 | 정상 샘플과 형태 비교 |
| 구조 변화 | 깨짐, 찌그러짐, 변형, 구멍 주변 이상 확인 | 경계선과 중심 구조 확인 |
| 구조/연결 상태 | 케이블 연결부, 제품 연결부, 구조 위치 이상 확인 | 연결부 주변 heatmap 확인 |
| 표면 손상 | 스크래치, 찍힘, 오염, 국소 손상 확인 | 원본 확대 확인 |
| 촬영 조건 영향 | 조명 반사, 초점 흐림, 위치 흔들림으로 인한 오탐 또는 미탐 가능성 확인 | 동일 조건 재촬영 후 score와 heatmap 변화 확인 |

## 4. 사용 Object 카테고리별 주요 해석 관점

| 카테고리 | 주요 확인 관점 | 예시 이상 유형 | 우선 확인 위치 |
| --- | --- | --- | --- |
| bottle | 전체 형태, 병목/바닥 구조, 표면 오염, 파손 여부 | 깨짐, 오염, 형태 이상, 표면 손상 | 외곽 경계, 병목, 바닥 주변 |
| cable | 선의 배치, 연결부 위치, 꼬임 또는 꺾임 여부 | 꼬임, 꺾임, 연결 이상, 단선 의심 | 연결부, 선이 꺾인 위치, 겹침 부위 |
| capsule | 표면 상태, 형태, 찍힘 또는 균열 여부 | 균열, 오염, 찍힘, 인쇄 불량, 압착 또는 형태 변형 | 표면 국소 영역, 가장자리 |
| hazelnut | 전체 형태, 표면 손상, 깨짐 또는 찍힘 여부 | 균열, 찍힘, 구멍, 절단, 표면 손상, 형태 이상 | 외곽 경계, 표면 손상 부위 |
| metal_nut | 금속 표면, 구멍 주변, 외곽 형태, 변형 여부 | 스크래치, 찍힘, 변형, 색상 이상, 방향 이상, 오염 | 구멍 주변, 외곽 경계, 금속 표면 |

Object 계열에서는 heatmap이 제품 경계, 연결부, 구멍 주변, 금속 표면의 국소 영역에 집중되는 경우 실제 구조적 이상 가능성을 우선 확인한다. 다만 제품 위치 변화, 조명 반사, 초점 흐림도 유사한 heatmap을 만들 수 있으므로 원본 이미지와 재촬영 결과를 함께 확인한다.

## 5. Object 계열 주요 결함 유형별 해석 기준

| 결함 유형 | 설명 | 관련 카테고리 | 작업자 확인 기준 |
| --- | --- | --- | --- |
| 형태 변형 | 제품의 외곽 모양이나 전체 구조가 정상과 다른 경우 | bottle, capsule, hazelnut, metal_nut | 정상 샘플과 외곽선, 중심축, 크기 비교 |
| 깨짐/균열 | 제품 일부가 깨지거나 표면에 선형 균열이 나타나는 경우 | bottle, capsule, hazelnut | 얇은 선 형태 heatmap과 원본 확대 확인 |
| 표면 오염 | 정상 표면과 다른 색상, 얼룩, 이물질이 보이는 경우 | bottle, capsule, hazelnut, metal_nut | 조명 반사와 실제 오염 구분 |
| 연결/배치 이상 | 선이나 연결부가 정상 위치에서 벗어나거나 꼬이는 경우 | cable | 연결부 주변, 꺾임 부위, 겹침 부위 확인 |
| 구멍/경계 주변 이상 | 구멍 주변, 제품 경계, 금속 외곽에서 비정상적 손상이 보이는 경우 | metal_nut | 구멍 내부/외부 경계, 반사 여부 확인 |
| 국소 찍힘/스크래치 | 작은 점, 찍힘, 긁힘이 국소 영역에 나타나는 경우 | capsule, hazelnut, metal_nut | 작은 점 형태 heatmap과 원본 확대 확인 |

원본 이미지에서 깨짐, 균열, 찍힘, 오염 등 결함이 육안으로 보이지만 anomaly score가 낮거나 heatmap이 약한 경우에는 미탐 가능성이 있다. 이 경우 결과를 정상으로 단정하지 않고 재검사 결과와 함께 기록한 뒤 후속 확인을 요청한다.

## 6. 카테고리별 요약 해석 관점

아래 내용은 object 5개 카테고리의 핵심 해석 관점을 요약한 것이다. 카테고리별 상세 결함 판정 기준, 재검사 조건, 불량 의심 조건은 `Object_카테고리별_결함판정기준서_v1`에서 다룬다.

### 6.1 bottle

bottle 카테고리는 전체 형태, 병목, 바닥, 표면 오염 및 파손 여부를 중심으로 확인한다. Heatmap이 병목이나 외곽 경계에 집중되면 형태 이상, 깨짐, 위치 변화 가능성을 확인한다. 표면에 넓게 퍼진 heatmap은 오염 또는 조명 반사 가능성을 함께 검토한다.

### 6.2 cable

cable 카테고리는 선의 배치, 연결부, 꼬임, 꺾임, 단선 의심 영역을 중심으로 확인한다. 케이블은 정상 상태에서도 위치 변화가 생길 수 있으므로, heatmap이 연결부나 꺾임 부위에 나타날 때 실제 결함인지 정상 배치 차이인지 구분해야 한다.

### 6.3 capsule

capsule 카테고리는 표면 상태, 형태, 찍힘, 균열, 오염을 중심으로 확인한다. 작은 점 형태 heatmap은 국소 찍힘이나 오염 가능성을 나타낼 수 있고, 선 형태 heatmap은 균열 가능성을 확인해야 한다.

### 6.4 hazelnut

hazelnut 카테고리는 전체 형태와 표면 손상을 중심으로 확인한다. 외곽 경계가 정상과 다르거나 표면에 국소 손상, 찍힘, 균열이 보이는 경우 이상 가능성이 있다. 자연물 형태 특성상 정상 변형과 결함을 구분하기 위해 정상 샘플과 비교가 필요하다.

### 6.5 metal_nut

metal_nut 카테고리는 금속 표면, 구멍 주변, 외곽 형태, 변형 여부를 중심으로 확인한다. 금속 표면은 조명 반사가 강하게 나타날 수 있으므로, heatmap이 넓게 퍼진 경우 실제 스크래치인지 반사인지 구분해야 한다. 구멍 주변에 국소적으로 heatmap이 집중되면 변형, 오염, 찍힘 가능성을 확인한다.

## 7. Heatmap / Anomaly Map 해석 기준

Object 계열에서 heatmap 또는 anomaly map은 모델이 정상 object 구조와 다르다고 판단한 위치를 보여준다. Heatmap은 확정 불량 위치가 아니라 작업자가 우선 확인해야 할 점검 영역이다.

Object 계열에서는 제품 위치나 회전, 촬영 각도 차이만으로도 제품 경계 부근에 heatmap이 나타날 수 있으므로, heatmap 위치가 실제 결함인지 정상 위치 변화인지 반드시 원본 이미지와 정상 샘플을 함께 비교해야 한다.

| Heatmap 형태 | 가능 해석 | 확인 항목 |
| --- | --- | --- |
| 제품 경계 집중 | 형태 변형, 위치 어긋남, 외곽 파손 또는 경계 오탐 | 정상 샘플과 외곽선 비교 |
| 연결부 집중 | 케이블 연결 이상, 꺾임, 접촉부 문제 가능성 | 연결부 원본 확대 확인 |
| 구멍 주변 집중 | metal_nut 변형, 오염, 찍힘 가능성 | 구멍 내부/외부 경계 확인 |
| 작은 점 형태 | 국소 오염, 찍힘, 작은 결함 가능성 | 원본 이미지 확대 확인 |
| 얇은 선 형태 | 균열, 스크래치 가능성 | 선형 손상 여부 확인 |
| 넓게 퍼짐 | 조명 반사, 초점 흐림, 배경 변화 가능성 | 촬영 조건 확인 후 재촬영 |

Pixel-level AUROC와 PRO는 heatmap/anomaly map이 실제 결함 위치를 얼마나 잘 가리키는지 평가하기 위한 지표이다. 이 문서에서는 작업자 해석 기준을 중심으로 설명하며, 자세한 지표 정의는 Heatmap_AnomalyMap_해석가이드_v1에서 다룬다.

## 8. Object 계열 판정 결과 해석

### 8.1 Object 계열 판정 결과 해석

| 상황 | 해석 | 권장 조치 |
| --- | --- | --- |
| score 낮음 + heatmap 약함 | 정상 가능성이 높음 | 정상 처리 가능 |
| score 중간 + heatmap 국소 집중 | 작은 결함 또는 경계 구간 가능성 | 원본 확대 확인 후 재검사 |
| score 높음 + object 구조 부위 집중 | 실제 구조적 이상 가능성 높음 | 후속 확인 또는 불량 의심 등록 |
| score 높음 + 넓은 heatmap | 촬영 조건 문제 또는 배경 변화 가능성 | 조명/초점/위치 확인 후 재촬영 |

정상/재검사/불량 의심의 정확한 threshold는 모델 버전, 카테고리, 검증 데이터에 따라 달라진다. 본 문서에서는 카테고리별 해석 관점과 작업자 확인 절차를 설명하며, threshold 운영 기준과 정상/재검사/불량 의심 판정 기준은 `정상_재검사_불량_판정기준서_v1`에서 다룬다.

본 문서에서 사용하는 score 낮음/중간/높음, heatmap 약함/국소 집중/넓게 분산 등의 표현은 모델 실험 결과 확정 전 사용하는 정성적 해석 표현이다. 실제 운영 단계의 threshold 및 정량 기준은 모델 버전, 카테고리별 검증 결과에 따라 별도 설정하며, 자세한 기준은 `Heatmap_AnomalyMap_해석가이드_v1` 및 `정상_재검사_불량_판정기준서_v1`에서 다룬다.

### 8.2 추가 상태: 반복 감지

| 추가 상태 | 의미 | 권장 조치 |
| --- | --- | --- |
| 반복 감지 | 재검사 또는 반복 촬영 과정에서 동일 위치에 heatmap이 반복적으로 나타나는 상태 | 실제 결함 가능성이 높아지므로 결과 기록 및 후속 확인 대상으로 처리 |

반복 감지는 기본 판정 결과가 아니라 추가 상태이다. 기본 판정은 정상, 재검사, 불량 의심을 기준으로 표시하고, 반복 감지는 재검사 또는 후속 확인 판단을 보조하는 정보로 활용한다.

## 9. 작업자 확인 절차

1. 검사 카테고리가 object 계열인지 확인한다.

2. anomaly score와 판정 결과를 확인한다.

3. 원본 이미지를 확인하고 제품의 전체 형태를 정상 샘플과 비교한다.

4. Heatmap 또는 Anomaly Map이 집중된 위치를 확인한다.

5. 제품 경계, 연결부, 구멍 주변, 표면 손상 부위를 우선 확인한다.

6. 조명 반사, 초점 흐림, 제품 위치 변화가 있는지 확인한다.

7. 필요한 경우 동일 조건에서 재촬영한다.

8. 재검사에서도 동일 위치에 heatmap이 반복되면 반복 감지 추가 상태로 기록하고 후속 확인 대상으로 기록한다.

9. 최종 조치 결과와 확인 내용을 기록한다.

## 10. 오탐/미탐 재검사 유의사항

Object 계열은 제품 위치가 조금만 달라져도 경계 부위에 heatmap이 나타날 수 있다.

금속 표면이나 유광 재질은 조명 반사로 인해 score가 높아질 수 있다.

케이블처럼 형태 변화가 큰 카테고리는 정상 배치 차이와 실제 결함을 구분해야 한다.

작은 국소 heatmap은 실제 결함일 수 있지만 먼지, 압축 노이즈, 초점 문제일 수도 있다.

문서에 없는 원인은 단정하지 않고, 원본 이미지와 재검사 결과를 함께 확인한다.

작업자는 heatmap을 확정 불량 위치가 아니라 점검 우선 영역으로 해석한다.

원본 이미지에서 결함이 보이지만 score가 낮거나 heatmap이 약한 경우에는 미탐 가능성이 있으므로 정상으로 단정하지 않는다.

미탐이 의심되는 결과는 원본 이미지, heatmap, 재촬영 결과를 함께 기록하고 후속 확인 대상으로 기록한다.

## 11. 관리자 참고: Object 계열 성능 해석 시 주의사항

모델 실험에서 object 평균 성능을 계산하는 경우, 본 프로젝트의 object 평균은 MVTec AD 전체 object 10개가 아니라 프로젝트 초기 실험에서 선택한 5개 object 카테고리 기준으로 해석한다.

Image-level AUROC는 object 이미지가 정상인지 이상인지 구분하는 성능을 보여주며, Pixel-level AUROC와 PRO는 object 결함 위치를 heatmap이 얼마나 잘 가리키는지 평가한다. F1-score는 threshold 적용 후 실제 정상/불량 의심 판정의 균형을 확인하는 지표이다.
