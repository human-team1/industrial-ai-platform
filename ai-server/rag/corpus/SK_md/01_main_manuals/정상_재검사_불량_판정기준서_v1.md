# 정상 / 재검사 / 불량 의심 판정기준서

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 제공하는 정상, 재검사, 불량 의심 판정의 의미와, 저신뢰·반복 감지와 같은 추가 상태의 작업자 대응 기준을 설명하기 위한 문서이다.

본 프로젝트는 이미지 기반 이상탐지 모델을 통해 anomaly score, heatmap/anomaly map, image-level 판정 결과를 제공한다. 사용자는 모델 결과를 최종 확정 판정으로 단정하지 않고, 원본 이미지, 시각화 결과, 재검사 결과를 함께 확인해야 한다.

이 문서는 판정 정책의 공통 기준을 제공하며, 카테고리별 결함 기준은 Object/Texture 카테고리별 결함판정기준서에서, heatmap 해석 기준은 Heatmap_AnomalyMap_해석가이드_v1에서 상세히 다룬다.

본 문서는 모델의 판정 결과를 어떻게 해석하고 어떤 후속 조치를 수행할지 정리한 운영형 기준서이다. 정확한 threshold 수치는 모델 버전, 카테고리, 검증 데이터에 따라 별도 관리한다.

## 3. 기존 판정 결과와 추가 상태

### 3.1 기본 판정 결과

본 프로젝트의 기본 판정 결과는 작업자가 빠르게 의사결정할 수 있도록 정상, 재검사, 불량 의심으로 구분한다. 저신뢰, 반복 감지, 촬영 조건 의심은 기본 판정이 아니라 추가 상태/사유로 관리한다. 불량 의심은 자동 확정 불량이 아니라 후속 확인 또는 불량 의심 등록이 필요한 상태를 의미한다.
반복 감지는 기본 판정 결과가 아니라, 재검사 또는 반복 촬영 과정에서 동일 위치에 heatmap이 반복적으로 나타나는 경우 표시하는 추가 상태이다. 반복 감지가 발생하면 실제 결함 가능성이 높아지므로 결과 기록 및 후속 확인 대상으로 처리한다.

| 판정 | 의미 | 작업자 기본 조치 |
| --- | --- | --- |
| 정상 | score가 낮고 heatmap이 약하거나 원본에서 결함이 확인되지 않는 상태 | 정상 처리 가능. 단, 반복 이력은 결과 화면에서 확인한다. |
| 재검사 | score가 경계 구간이거나 heatmap은 있으나 원본 결함이 불명확한 상태 | 동일 조건으로 재촬영하고 정상 샘플과 비교한다. |
| 불량 의심 | score가 높고 카테고리별 결함 위치에 heatmap이 명확하게 집중되는 상태 | 후속 확인 또는 불량 의심 대상으로 등록한다. |

### 3.2 추가 상태: 추가 상태/사유

| 추가상태 | 의미 | 작업자 조치 |
| --- | --- | --- |
| 저신뢰 | 조명, 초점, 위치 변화, 입력 이미지 품질 문제로 결과 신뢰도가 낮은 상태 | 촬영 조건과 설비 상태를 확인한 뒤 재촬영한다. |
| 반복 감지 | 재검사 또는 반복 촬영에서도 동일 위치에 heatmap이 반복되는 상태 | 결과를 기록하고 후속 확인 또는 불량 의심 대상으로 등록한다. |
| 촬영 조건 의심 | 조명 반사, 초점 흐림, 위치 변화, ROI 문제 등이 결과에 영향을 준 것으로 보이는 상태 | 촬영 조건을 점검한 뒤 동일 조건으로 재촬영한다. |

## 4. Score 구간과 threshold 해석 원칙

본 문서에서 사용하는 score 낮음/중간/높음은 고정된 수치 기준이 아니라, 모델 실험 결과 확정 전 사용하는 정성적 표현이다. 실제 운영 시에는 모델 버전, 카테고리, 검증 데이터에 따라 threshold를 별도로 설정한다.

또한 heatmap 약함/국소 집중/넓게 분산은 작업자가 시각적으로 확인하는 패턴을 설명하기 위한 표현이다. 추후 성능 테스트 결과가 확보되면 heatmap intensity, 활성화 면적 비율, 동일 위치 반복 여부 등의 기준을 별도 설정 파일 또는 운영 기준서에 반영할 수 있다.

| 표현 | 현재 문서에서의 의미 | 추후 정량화 가능 기준 |
| --- | --- | --- |
| score 낮음 | 정상 가능성이 높다고 해석되는 낮은 이상 점수 구간 | 모델/카테고리별 정상 threshold 이하 |
| score 중간 | 정상과 이상 사이의 경계 또는 재검사가 필요한 점수 구간 | 재검사 구간 threshold 범위 |
| score 높음 | 이상 가능성이 높다고 해석되는 높은 이상 점수 구간 | 불량 의심 threshold 이상 |
| heatmap 약함 | 색상 강도가 낮고 원본에서 결함이 명확하지 않은 상태 | heatmap intensity 평균/최댓값 |
| heatmap 국소 집중 | 특정 작은 영역에 강한 반응이 나타나는 상태 | 활성화 면적 비율, connected component |
| heatmap 넓게 분산 | 검사 대상 전반에 반응이 넓게 퍼진 상태 | 전체 ROI 대비 활성화 면적 |
| 동일 위치 반복 | 재검사에서도 유사 위치에 반응이 반복되는 상태 | 좌표 또는 영역 overlap |

## 5. 판정 조합별 해석 기준

| 상황 | 해석 | 작업자 조치 |
| --- | --- | --- |
| score 낮음 + heatmap 약함 | 정상 가능성이 높음 | 정상 처리 가능. 단, 반복 이력은 결과 화면에서 확인한다. |
| score 중간 + heatmap 국소 집중 | 작은 결함 또는 경계 구간 가능성 | 원본 확대 확인 후 동일 조건으로 재검사한다. |
| score 높음 + heatmap 국소 집중 | 실제 결함 가능성이 높음 | 후속 확인 또는 불량 의심 대상으로 등록한다. |
| score 높음 + heatmap 넓게 분산 | 촬영 조건 문제 또는 배경/조명 영향 가능성 | 조명, 초점, 위치를 점검하고 동일 조건으로 재촬영한다. |
| score 낮음 + 원본 결함 의심 | 모델이 미세 결함을 약하게 본 가능성 | 원본 결함이 명확하면 재검사 또는 후속 확인을 요청한다. |

불량 의심은 자동 확정 불량을 의미하지 않는다. 작업자는 원본 이미지, heatmap 위치, 재검사 결과를 함께 확인한 뒤 후속 확인 또는 불량 의심 등록 여부를 결정한다.

- 추가 상태 조합별 해석

| 추가 상태/상황 | 해석 | 작업자 조치 |
| --- | --- | --- |
| 저신뢰 + 이미지 품질 문제 | 초점 흐림, 밝기 불균형, ROI 누락 등으로 결과 신뢰도 낮음 | 입력 이미지와 설비 상태를 확인하고 재촬영한다. |
| 동일 위치 반복 감지 | 실제 결함 가능성 증가 | 결과를 기록하고 후속 확인을 수행한다. |

## 6. 경계 구간 및 재검사 기준

재검사는 모델 결과가 애매하거나 입력 이미지 품질이 충분하지 않을 때 작업자가 동일 조건에서 다시 확인하도록 유도하는 절차이다. 재검사 구간은 오탐과 미탐을 줄이기 위한 운영 장치이다.

| 재검사 권장 상황 | 확인 항목 | 후속 조치 |
| --- | --- | --- |
| score가 중간 구간에 위치함 | 원본 이미지와 heatmap 위치가 실제 결함과 일치하는지 확인 | 동일 조건 재촬영 후 결과 비교 |
| heatmap은 있으나 원본 결함이 불명확함 | 원본 확대, 정상 샘플, 촬영 조건 확인 | 재검사 후 반복 여부 판단 |
| heatmap이 넓게 퍼짐 | 조명 반사, 초점 흐림, 배경 변화 확인 | 설비 상태 점검 후 재촬영 |
| object의 제품 위치/회전이 달라짐 | 외곽선, 연결부, 구멍 주변 위치 비교 | 위치 정렬 후 재촬영 |
| texture의 패턴 정렬이 어긋남 | 반복 패턴 연속성, 초점, 조명 상태 확인 | 정상 texture 샘플과 비교 후 재촬영 |
| 결과와 작업자 육안 판단이 다름 | 모델 결과, 원본, heatmap, 정상 샘플을 함께 확인 | 후속 확인 요청 |

## 7. 저신뢰 결과 처리 기준

저신뢰 결과는 모델이 명확히 정상 또는 불량 의심으로 판단하기 어렵거나, 입력 이미지 품질 문제로 결과 신뢰도가 낮은 상태를 의미한다.

| 저신뢰 원인 | 예시 | 작업자 조치 |
| --- | --- | --- |
| 이미지 품질 저하 | 초점 흐림, motion blur, 과도한 압축 노이즈 | 이미지 재촬영 및 카메라 상태 확인 |
| 조명 조건 문제 | 반사, 그림자, 밝기 불균형, 과노출/저노출 | 조명 상태 조정 후 동일 조건 재촬영 |
| ROI 문제 | 검사 대상이 잘리거나 배경이 과도하게 포함됨 | ROI 설정과 crop 상태 확인 |
| 제품 위치 변화 | 회전, 기울어짐, 위치 흔들림 | 정렬 상태 확인 후 재촬영 |
| 정상 변동이 큰 카테고리 | hazelnut, leather, wood 등 자연 변형/질감 변화 | 정상 샘플 다수와 비교 후 재검사 |

## 8. 오탐 및 미탐 관리 기준

- 오탐은 정상 이미지 또는 정상 변형을 이상으로 판단한 경우이다.

- 미탐은 실제 이상 이미지 또는 결함 영역을 정상으로 판단한 경우이다.

- 오탐이 반복되면 조명, 초점, 위치, 배경, threshold 설정을 함께 점검한다.

- 미탐이 의심되면 원본 이미지에서 결함이 명확한지 확인하고, 입력 해상도와 heatmap 품질을 함께 확인한다.

- score가 낮더라도 원본 이미지에서 명확한 결함이 보이면 재검사 또는 후속 확인을 요청한다.

- 문서에 없는 원인은 단정하지 않고 원본 이미지, 모델 결과, 재검사 결과를 함께 확인한다.

| 발생 유형 | 기록해야 할 정보 | 개선 검토 항목 |
| --- | --- | --- |
| 오탐 | 카테고리, score, heatmap 위치, 오탐 의심 원인, 촬영 조건 | threshold 조정 검토, 조명/ROI 점검, 정상 샘플 보강 |
| 미탐 | 원본 결함 위치, 모델 score, heatmap 반응 여부, 결함 유형 | 입력 해상도, 모델 후보, threshold, pixel-level 성능 점검 |
| 저신뢰 반복 | 카메라/조명 상태, 재촬영 결과, 반복 발생 시간대 | 설비 점검, 촬영 조건 표준화, SOP 보완 |

| 추정 결함 유형 | object: 형태 변형/깨짐/오염/연결 이상 등, texture: 스크래치/오염/균열/패턴 깨짐 등 |
| 원본 확인 결과 | 실제 결함 확인 여부 |
| 오탐/미탐 의심 원인 | 조명 반사, 초점 흐림, 위치 변화, 정렬 차이, 자연 질감 변화 등 |
| 재촬영 여부 | 동일 조건 재촬영 수행 여부 |
| 재검사 결과 | 재촬영 후 정상/재검사/불량 의심 중 확인된 판정 결과와 추가 상태를 기록한다. |
| 최종 조치 | 정상 처리, 재검사, 후속 확인, 불량 의심 등록 |

## 11. 관리자 참고: threshold 운영 원칙

threshold는 모델 버전, 카테고리, 검증 데이터, 운영 목표에 따라 달라진다. 동일한 anomaly score라도 모델이 다르면 점수 분포가 달라질 수 있으므로, threshold는 모델별·카테고리별로 관리한다.

| 관리 항목 | 설명 |
| --- | --- |
| 모델 버전 | threshold가 어떤 모델과 backbone 설정에서 산출되었는지 기록한다. |
| 카테고리별 threshold | object/texture 및 category별 score 분포가 다를 수 있으므로 별도 관리한다. |
| 정상/재검사/불량 의심 구간 | 운영 단계에서는 각 구간의 수치 기준을 설정 파일 또는 운영 테이블에서 관리한다. |
| F1-score | threshold 적용 후 정상/불량 의심 판정 균형을 확인하는 지표로 사용한다. |
| 오탐/미탐 비율 | 운영 목표에 따라 threshold 조정 시 함께 확인한다. |
| 변경 이력 | threshold 변경 전후의 사유, 검증 결과, 승인 여부를 기록한다. |
