# Texture 계열 결함해석가이드

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 사용하는 MVTec AD texture 계열 카테고리의 결함 해석 기준을 설명하기 위한 문서이다.

본 프로젝트는 이미지 기반 이상탐지 모델을 통해 제품 표면의 정상/이상 여부를 판단하고, anomaly score, 판정 결과, heatmap 또는 anomaly map을 제공한다. 작업자와 관리자가 texture 계열 결과를 해석하려면 각 카테고리의 표면 패턴, 질감 변화, 주요 이상 유형, heatmap 집중 형태의 의미를 이해해야 한다.

이 문서는 texture 계열 공통 해석 기준과 프로젝트에서 사용하는 texture 5개 카테고리의 요약 해석 관점을 제공한다. 카테고리별 상세 판정 기준과 세부 점검 절차는 별도 문서인 `Texture_카테고리별_결함판정기준서_v1`에서 보완한다.

## 3. Texture 계열 결함 해석 개요

Texture 계열은 제품의 전체 형태보다 표면 패턴, 반복 무늬, 질감, 색상 변화, 국소 손상 여부가 중요한 카테고리이다. Object 계열이 구조와 형태 차이를 중심으로 해석되는 것과 달리, texture 계열은 정상 표면 패턴과 비교하여 미세한 표면 변화와 반복 패턴의 깨짐을 확인하는 것이 핵심이다.

| 해석 관점 | 설명 | 작업자 확인 포인트 |
| --- | --- | --- |
| 표면 패턴 | 반복 무늬나 표면 배열이 정상과 다른지 확인 | 정상 샘플과 패턴 연속성 비교 |
| 질감 변화 | 표면 결, 거칠기, 광택 또는 색감이 달라졌는지 확인 | 동일 영역의 정상 texture와 비교 |
| 국소 손상 | 작은 점, 구멍, 찍힘, 미세 결함 확인 | 원본 이미지 확대 확인 |
| 선형 손상 | 스크래치, 균열처럼 선 형태 이상 확인 | 얇은 선 형태 heatmap 확인 |
| 촬영 조건 영향 | 조명 반사, 그림자, 초점 흐림으로 인한 오탐 또는 미탐 가능성 확인 | 동일 조건 재촬영 후 score와 heatmap 변화 확인 |

## 4. 사용 Texture 카테고리별 주요 해석 관점

| 카테고리 | 주요 확인 관점 | 예시 이상 유형 | 우선 확인 위치 |
| --- | --- | --- | --- |
| carpet | 반복 패턴, 섬유 결, 표면 얼룩, 국소 손상 여부 | 패턴 깨짐, 오염, 얼룩, 색상 변화, 국소 손상 | 반복 패턴이 끊긴 위치, 얼룩 부위 |
| grid | 격자 반복 구조, 선 끊김, 미세 결함 여부 | 격자선 끊김, 패턴 깨짐, 색상 변화, 국소 결함 | 격자 교차점, 선이 끊긴 위치 |
| leather | 표면 질감, 주름, 스크래치, 색상 변화 여부 | 스크래치, 오염, 색상 변화, 질감 변화, 찍힘 | 선형 손상 위치, 색상 변화 부위 |
| tile | 표면 균열, 오염, 파손, 색상 변화 여부 | 균열, 오염, 색상 변화, 표면 파손, 얼룩 | 균열선, 모서리, 표면 국소 영역 |
| wood | 나뭇결, 스크래치, 찍힘, 색상 변화 여부 | 스크래치, 찍힘, 색상 변화, 결 변화, 오염 | 나뭇결이 끊긴 위치, 선형 손상 부위 |

Texture 계열에서는 heatmap이 얇은 선, 작은 점, 반복 패턴 일부, 얼룩 형태로 나타나는 경우 실제 표면 결함 가능성을 우선 확인한다. 다만 조명 방향, 그림자, 초점 흐림, 재질의 자연스러운 질감 차이도 유사한 heatmap을 만들 수 있으므로 원본 이미지와 재촬영 결과를 함께 확인한다.

## 5. Texture 계열 주요 결함 유형별 해석 기준

| 결함 유형 | 설명 | 관련 카테고리 | 작업자 확인 기준 |
| --- | --- | --- | --- |
| 스크래치 | 표면에 얇은 선 형태의 손상이 나타나는 경우 | leather, tile, wood | 얇은 선 형태 heatmap과 원본 확대 확인 |
| 얼룩/오염 | 정상 표면과 다른 색상, 얼룩, 이물질이 보이는 경우 | carpet, leather, tile, wood | 조명 반사와 실제 오염 구분 |
| 균열/파손 | 표면이 갈라지거나 일부가 깨진 형태를 보이는 경우 | tile, wood | 선형 heatmap, 모서리 손상 여부 확인 |
| 패턴 깨짐 | 반복 패턴이나 격자 구조가 끊기거나 어긋나는 경우 | carpet, grid | 주변 반복 구조와 연속성 비교 |
| 질감 변화 | 표면 결, 광택, 거칠기, 색상 또는 색감이 정상과 다른 경우 | leather, wood, carpet | 정상 texture 샘플과 비교 |
| 국소 점 결함 | 작은 점, 구멍, 찍힘이 국소 영역에 나타나는 경우 | grid, tile, leather | 작은 점 형태 heatmap과 원본 확대 확인 |

원본 이미지에서 스크래치, 균열, 오염, 패턴 깨짐이 육안으로 보이지만 anomaly score가 낮거나 heatmap이 약한 경우에는 미탐 가능성이 있다. 이 경우 결과를 정상으로 단정하지 않고 재검사 결과와 함께 기록한 뒤 후속 확인을 요청한다.

## 6. 카테고리별 요약 해석 관점

아래 내용은 texture 5개 카테고리의 핵심 해석 관점을 요약한 것이다. 카테고리별 상세 결함 판정 기준, 재검사 조건, 불량 의심 조건은 `Texture_카테고리별_결함판정기준서_v1`에서 다룬다.

### 6.1 carpet

carpet 카테고리는 반복 패턴, 섬유 결, 얼룩, 국소 손상 여부를 중심으로 확인한다. Heatmap이 반복 패턴이 끊긴 위치나 얼룩 부위에 집중되면 패턴 깨짐, 오염, 표면 손상 가능성을 확인한다. 단, 섬유 질감의 자연스러운 변화와 실제 결함을 구분하기 위해 정상 샘플과 비교가 필요하다.

### 6.2 grid

grid 카테고리는 격자 반복 구조와 선의 연속성을 중심으로 확인한다. Heatmap이 격자선이 끊긴 위치, 교차점, 국소 영역에 집중되면 패턴 깨짐 또는 미세 결함 가능성을 확인한다. 격자 구조는 작은 위치 변화에도 민감할 수 있으므로 원본 이미지 정렬 상태도 함께 확인한다.

### 6.3 leather

leather 카테고리는 표면 질감, 주름, 스크래치, 색상 변화, 국소 오염을 중심으로 확인한다. 얇은 선 형태 heatmap은 스크래치 가능성을 나타낼 수 있고, 넓게 퍼진 heatmap은 조명 반사나 질감 변화 가능성을 함께 검토한다.

### 6.4 tile

tile 카테고리는 표면 균열, 파손, 오염, 색상 변화 여부를 중심으로 확인한다. Heatmap이 길고 얇은 선 형태로 나타나면 균열 가능성을 우선 확인하고, 모서리나 표면 국소 영역에 집중되면 파손 또는 오염 가능성을 검토한다.

### 6.5 wood

wood 카테고리는 나뭇결의 연속성, 스크래치, 찍힘, 색상 변화 여부를 중심으로 확인한다. 나뭇결은 정상 상태에서도 자연스러운 변화가 있으므로, heatmap이 나뭇결 방향과 다르게 끊기거나 국소적으로 강하게 나타나는지 확인해야 한다.

## 7. Heatmap / Anomaly Map 해석 기준

Texture 계열에서 heatmap 또는 anomaly map은 모델이 정상 표면 패턴과 다르다고 판단한 위치를 보여준다. Heatmap은 확정 불량 위치가 아니라 작업자가 우선 확인해야 할 점검 영역이다.

Texture 계열에서는 표면의 미세한 변화, 조명 반사, 그림자, 초점 흐림이 모두 heatmap에 영향을 줄 수 있으므로, heatmap 위치가 실제 결함인지 촬영 조건에 의한 변화인지 원본 이미지와 정상 샘플을 함께 비교해야 한다.

| Heatmap 형태 | 가능 해석 | 확인 항목 |
| --- | --- | --- |
| 얇은 선 형태 | 스크래치, 균열, 나뭇결 이상 가능성 | 선형 손상 여부 확인 |
| 작은 점 형태 | 국소 오염, 찍힘, 작은 구멍 가능성 | 원본 이미지 확대 확인 |
| 반복 패턴 일부 집중 | grid, carpet 패턴 깨짐 가능성 | 주변 반복 구조와 비교 |
| 얼룩 형태 | 오염, 색상 변화, 조명 그림자 가능성 | 조명 조건과 표면 상태 확인 |
| 넓게 퍼짐 | 조명 반사, 초점 흐림, 배경 변화 가능성 | 촬영 조건 확인 후 재촬영 |
| 모서리/경계 집중 | 표면 파손 또는 경계 오탐 가능성 | 원본과 정상 샘플 비교 |

Pixel-level AUROC와 PRO는 heatmap/anomaly map이 실제 결함 위치를 얼마나 잘 가리키는지 평가하기 위한 지표이다. 이 문서에서는 작업자 해석 기준을 중심으로 설명하며, 자세한 지표 정의는 `Heatmap_AnomalyMap_해석가이드_v1`에서 다룬다.

## 8. Texture 계열 판정 결과 해석

| 상황 | 해석 | 권장 조치 |
| --- | --- | --- |
| score 낮음 + heatmap 약함 | 정상 가능성이 높음 | 정상 처리 가능 |
| score 중간 + 얇은 선/작은 점 heatmap | 작은 표면 결함 또는 경계 구간 가능성 | 원본 확대 확인 후 재검사 |
| score 높음 + texture 패턴 부위 집중 | 실제 표면 결함 가능성 높음 | 후속 확인 또는 불량 의심 등록 |
| score 높음 + 넓은 heatmap | 조명/초점/그림자 문제 또는 표면 전체 변화 가능성 | 조명/초점 확인 후 재촬영 |

texture 계열에서는 표면 결함과 촬영 조건 문제가 유사한 heatmap 형태로 나타날 수 있으므로, 불량 의심 등록 전 원본 이미지와 재촬영 결과를 함께 확인한다.

정상/재검사/불량 의심의 정확한 threshold는 모델 버전, 카테고리, 검증 데이터에 따라 달라진다. 본 문서에서는 texture 계열 해석 관점과 작업자 확인 절차를 설명하며, threshold 운영 기준은 `정상_재검사_불량_판정기준서_v1`에서 다룬다.

본 문서에서 사용하는 score 낮음/중간/높음, heatmap 약함/국소 집중/넓게 분산 등의 표현은 모델 실험 결과 확정 전 사용하는 정성적 해석 표현이다. 실제 운영 단계의 threshold 및 정량 기준은 모델 버전, 카테고리별 검증 결과에 따라 별도 설정하며, 자세한 기준은 `Heatmap_AnomalyMap_해석가이드_v1` 및 `정상_재검사_불량_판정기준서_v1`에서 다룬다.

### 8.2 추가 상태: 반복 감지

| 추가 상태 | 의미 | 권장 조치 |
| --- | --- | --- |
| 반복 감지 | 재검사 또는 반복 촬영 과정에서 동일 위치에 heatmap이 반복적으로 나타나는 상태 | 실제 결함 가능성이 높아지므로 결과 기록 및 후속 확인 대상으로 처리 |

반복 감지는 기본 판정 결과가 아니라 추가 상태이다. 기본 판정은 정상, 재검사, 불량 의심을 기준으로 표시하고, 반복 감지는 재검사 또는 후속 확인 판단을 보조하는 정보로 활용한다.

## 9. 작업자 확인 절차

1. 검사 카테고리가 texture 계열인지 확인한다.

2. anomaly score와 판정 결과를 확인한다.

3. 원본 이미지를 확인하고 표면 패턴 또는 질감을 정상 샘플과 비교한다.

4. Heatmap 또는 Anomaly Map이 집중된 위치를 확인한다.

5. 스크래치, 얼룩, 균열, 패턴 깨짐, 질감 변화 부위를 우선 확인한다.

6. 조명 반사, 그림자, 초점 흐림, 촬영 위치 변화가 있는지 확인한다.

7. 필요한 경우 동일 조건에서 재촬영한다.

8. 재검사에서도 동일 위치에 heatmap이 반복되면 반복 감지 추가 상태로 기록하고 후속 확인 대상으로 기록한다.

9. 최종 조치 결과와 확인 내용을 기록한다.

## 10. 오탐/미탐 재검사 유의사항

Texture 계열은 조명 방향이나 표면 반사에 따라 heatmap이 넓게 나타날 수 있다.

반복 패턴이 있는 카테고리는 작은 정렬 차이만으로도 패턴 깨짐처럼 보일 수 있다.

카펫, 가죽, 나무처럼 자연스러운 질감 변화가 있는 표면은 정상 변형과 실제 결함을 구분해야 한다.

작은 국소 heatmap은 실제 결함일 수 있지만 먼지, 압축 노이즈, 초점 문제일 수도 있다.

문서에 없는 원인은 단정하지 않고, 원본 이미지와 재검사 결과를 함께 확인한다.

작업자는 heatmap을 확정 불량 위치가 아니라 점검 우선 영역으로 해석한다.

원본 이미지에서 스크래치, 균열, 오염, 패턴 깨짐이 보이지만 score가 낮거나 heatmap이 약한 경우에는 미탐 가능성이 있으므로 정상으로 단정하지 않는다.

미탐이 의심되는 결과는 원본 이미지, heatmap, 재촬영 결과를 함께 기록하고 후속 확인 대상으로 기록한다.

## 11. 관리자 참고: Texture 계열 성능 해석 시 주의사항

모델 실험에서 texture 평균 성능을 계산하는 경우, 본 프로젝트의 texture 평균은 MVTec AD texture 5개 카테고리인 carpet, grid, leather, tile, wood 기준으로 해석한다.

Image-level AUROC는 texture 이미지가 정상인지 이상인지 구분하는 성능을 보여주며, Pixel-level AUROC와 PRO는 texture 결함 위치를 heatmap이 얼마나 잘 가리키는지 평가한다. F1-score는 threshold 적용 후 실제 정상/불량 의심 판정의 균형을 확인하는 지표이다.
