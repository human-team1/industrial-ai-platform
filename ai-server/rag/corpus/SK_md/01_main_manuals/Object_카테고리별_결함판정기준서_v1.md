# Object 카테고리별 결함판정기준서

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 사용하는 MVTec AD object 5개 카테고리의 결함 판정 기준과 작업자 점검 절차를 설명하기 위한 문서이다.

본 프로젝트는 이미지 기반 이상탐지 모델을 통해 제품의 정상/이상 여부를 판단하고, anomaly score, 판정 결과, heatmap 또는 anomaly map을 제공한다. 작업자와 관리자가 object 카테고리별 결과를 해석하려면 각 카테고리의 구조적 특징, 주요 결함 유형, 재검사 조건, 불량 의심 조건을 구체적으로 이해해야 한다.

이 문서는 `Object_계열_결함해석가이드_v1`에서 설명한 공통 해석 관점을 바탕으로, bottle, cable, capsule, hazelnut, metal_nut 각각에 대한 상세 판정 기준과 점검 절차를 제공한다. RAG 기반 문서 질의응답, 결과 상세 설명, 작업자 대응 절차 추천의 근거 문서로 사용한다.

본 문서는 프로젝트 초기 실험에서 사용하는 object 5개 카테고리를 모두 포함한다. 계열 공통 해석 기준은 별도 문서인 `Object_계열_결함해석가이드_v1`에서 다루며, 본 문서는 카테고리별 상세 판정 기준과 점검 절차에 초점을 둔다.

## 3. 카테고리별 판정 기준 개요

Object 카테고리는 제품의 전체 형태, 외곽 구조, 연결 상태, 구멍 주변 구조, 표면 손상 여부를 중심으로 판정한다. 카테고리별로 결함이 나타나는 위치와 오탐 원인이 다르므로, 동일한 anomaly score와 heatmap 형태라도 카테고리 특성에 맞게 해석해야 한다.

| 카테고리 | 핵심 판정 관점 | 주요 결함 유형 | 주요 오탐 요인 |
| --- | --- | --- | --- |
| bottle | 외곽 형태, 병목/바닥 구조, 표면 상태 | 깨짐, 형태 변형, 오염, 표면 손상 | 위치 변화, 배경 반사, 조명 반사 |
| cable | 선의 배치, 연결부, 꼬임/꺾임 | 꼬임, 꺾임, 연결 이상, 단선 의심 | 정상 배치 차이, 겹침, 배경 패턴, 그림자 |
| capsule | 표면 상태, 가장자리, 인쇄/색상 변화 | 찍힘, 균열, 오염, 인쇄 불량, 압착 | 초점 흐림, 작은 먼지, 색상 편차 |
| hazelnut | 전체 형태, 외곽 경계, 표면 손상 | 균열, 구멍, 절단, 찍힘, 표면 손상 | 자연스러운 형태 변형, 표면 질감 차이 |
| metal_nut | 금속 표면, 구멍 주변, 외곽 형태 | 스크래치, 찍힘, 변형, 색상 이상, 오염 | 금속 반사, 방향 차이, 그림자 |

## 4. 공통 판정 흐름

카테고리별 세부 기준은 다르지만, object 계열 결과를 확인할 때는 다음 흐름을 기본으로 적용한다.

1. 검사 카테고리와 입력 이미지가 올바른지 확인한다.

2. anomaly score와 정상/재검사/불량 의심 판정 결과를 확인한다.

3. 원본 이미지를 열어 제품의 전체 형태와 위치를 확인한다.

4. heatmap 또는 anomaly map이 집중된 위치를 확인한다.

## 5. 카테고리별 우선 확인 위치와 비교한다.

## 6. 조명 반사, 초점 흐림, 위치 변화, 배경 변화 등 오탐 요인을 확인한다.

## 7. 필요한 경우 동일 조건에서 재촬영한다.

## 8. 재검사 또는 반복 촬영에서도 동일 위치에 heatmap이 반복되면 반복 감지 추가 상태로 기록하고, 후속 확인 또는 불량 의심 대상으로 등록한다.

## 9. 최종 확인 내용과 조치 결과를 기록한다.

## 5. 카테고리별 상세 판정 기준

카테고리별 불량 의심 조건에서 말하는 반복 집중은 기본 판정 결과가 아니라, 재검사 또는 반복 촬영 과정에서 동일 위치에 heatmap이 반복적으로 나타나는 추가 상태를 의미한다.

### 5.1 bottle

bottle 카테고리는 전체 형태, 병목, 바닥, 표면 오염 및 파손 여부를 중심으로 확인한다. Heatmap이 외곽 경계, 병목, 바닥 주변에 집중되면 형태 변형, 깨짐, 위치 변화 가능성을 우선 검토한다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 외곽 형태와 병목/바닥 구조가 명확하며, 표면 오염이나 파손이 판정에 영향을 준다. |
| 주요 결함 유형 | 깨짐, 표면 오염, 형태 이상, 표면 손상, 병목/바닥 주변 파손 |
| 우선 확인 위치 | 외곽 경계, 병목, 바닥 주변, 표면 국소 영역 |
| 재검사 조건 | score가 중간이고 heatmap이 외곽 또는 표면 일부에만 약하게 나타나는 경우 |
| 불량 의심 조건 | score가 높고 외곽 파손, 병목 손상, 표면 결함 위치에 heatmap이 반복 집중되는 경우 |
| 오탐 가능 원인 | 병의 위치 변화, 배경 반사, 조명 반사, 촬영 각도 차이 |
| 작업자 점검 | 정상 bottle 샘플과 외곽선, 병목, 바닥 형태를 비교하고 원본 이미지를 확대 확인한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 외곽 경계 | 형태 변형, 위치 어긋남, 경계 오탐 | 정상 샘플과 외곽선 비교 |
| 병목 주변 | 병목 손상 또는 촬영 위치 변화 | 병목 형태와 그림자 확인 |
| 바닥 주변 | 바닥 파손, 경계 손상, 반사 가능성 | 바닥 형태와 조명 반사 확인 |
| 표면 넓은 영역 | 오염 또는 조명 반사 가능성 | 표면 상태 확인 후 재촬영 |

### 5.2 cable

cable 카테고리는 선의 배치, 연결부 위치, 꼬임, 꺾임, 단선 의심 영역을 중심으로 확인한다. 케이블은 정상 상태에서도 위치 변화가 발생할 수 있으므로 정상 배치 차이와 실제 결함을 구분하는 것이 중요하다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 선형 구조와 연결부가 핵심이며, 정상 배치 변화가 비교적 크게 나타날 수 있다. |
| 주요 결함 유형 | 꼬임, 꺾임, 연결 이상, 단선 의심, 겹침, 배치 이상 |
| 우선 확인 위치 | 연결부, 선이 꺾인 위치, 겹침 부위, 케이블 끝단 |
| 재검사 조건 | heatmap이 선 주변에 약하게 나타나지만 원본에서 결함이 명확하지 않은 경우 |
| 불량 의심 조건 | 연결부 주변이나 꺾임 부위에 heatmap이 반복적으로 집중되고 실제 배치 이상이 확인되는 경우 |
| 오탐 가능 원인 | 정상 배치 차이, 케이블 위치 흔들림, 배경과의 겹침, 그림자 |
| 작업자 점검 | 정상 배치와 연결부 위치를 비교하고, 동일 조건 재촬영에서 같은 위치가 반복되는지 확인한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 연결부 | 연결 이상, 접촉부 문제, 위치 어긋남 | 연결부 확대 확인 |
| 꺾임 부위 | 꼬임, 꺾임, 단선 의심 | 케이블 흐름과 꺾임 정도 확인 |
| 겹침 부위 | 정상 겹침 또는 배치 이상 | 정상 샘플 배치와 비교 |
| 넓은 선 주변 | 배경 변화 또는 그림자 가능성 | 촬영 조건 확인 후 재촬영 |

### 5.3 capsule

capsule 카테고리는 표면 상태, 형태, 찍힘, 균열, 오염, 인쇄 불량 또는 압착 여부를 중심으로 확인한다. 작은 점 형태 heatmap은 국소 찍힘이나 오염을 의미할 수 있고, 얇은 선 형태 heatmap은 균열 가능성을 확인해야 한다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 작은 object이며 표면 국소 결함과 가장자리 형태 변화가 판정에 중요하다. |
| 주요 결함 유형 | 찍힘, 균열, 오염, 인쇄 불량, 압착 또는 형태 변형 |
| 우선 확인 위치 | 표면 국소 영역, 가장자리, 색상/인쇄 변화 부위 |
| 재검사 조건 | 작은 점 형태 heatmap이 있으나 원본 확대에서 명확한 결함이 확인되지 않는 경우 |
| 불량 의심 조건 | 동일 위치에 점/선 형태 heatmap이 반복되고 실제 찍힘, 균열, 인쇄 이상이 확인되는 경우 |
| 오탐 가능 원인 | 먼지, 초점 흐림, 압축 노이즈, 미세 색상 편차 |
| 작업자 점검 | 원본 이미지를 확대하여 점, 선, 색상 변화가 실제 표면 결함인지 확인한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 표면 작은 점 | 국소 찍힘, 오염, 작은 이물 | 원본 확대 확인 |
| 얇은 선 | 균열 또는 스크래치 가능성 | 선형 손상 여부 확인 |
| 가장자리 | 형태 변형, 압착, 경계 오탐 | 가장자리와 정상 샘플 비교 |
| 색상/인쇄 영역 | 인쇄 불량 또는 색상 편차 | 해당 영역 확대 확인 |

### 5.4 hazelnut

hazelnut 카테고리는 전체 형태, 외곽 경계, 표면 손상, 깨짐, 구멍 또는 절단 여부를 중심으로 확인한다. 자연물 특성상 정상 형태의 변동이 존재하므로 정상 샘플과 비교하여 실제 결함과 정상 변형을 구분해야 한다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 자연물 형태 특성상 정상 샘플 사이에도 외곽과 표면 질감 차이가 존재한다. |
| 주요 결함 유형 | 균열, 찍힘, 구멍, 절단, 표면 손상, 형태 이상 |
| 우선 확인 위치 | 외곽 경계, 표면 손상 부위, 구멍 또는 절단 의심 부위 |
| 재검사 조건 | heatmap이 표면 질감 차이에 넓게 퍼지거나 원본에서 결함이 불명확한 경우 |
| 불량 의심 조건 | 외곽 파손, 구멍, 절단, 깊은 균열 위치에 heatmap이 반복 집중되는 경우 |
| 오탐 가능 원인 | 자연스러운 모양 차이, 표면 질감 변화, 조명 그림자 |
| 작업자 점검 | 정상 hazelnut 샘플과 외곽 형태, 표면 질감, 구멍 여부를 비교한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 외곽 경계 | 형태 이상, 절단, 파손 가능성 | 정상 샘플과 외곽 비교 |
| 표면 국소점 | 찍힘, 오염, 작은 구멍 가능성 | 원본 확대 확인 |
| 선형 영역 | 균열 또는 표면 손상 가능성 | 선형 손상 여부 확인 |
| 넓은 표면 영역 | 자연스러운 질감 차이 또는 조명 영향 | 정상 샘플과 재촬영 비교 |

### 5.5 metal_nut

metal_nut 카테고리는 금속 표면, 구멍 주변, 외곽 형태, 변형 여부를 중심으로 확인한다. 금속 표면은 조명 반사에 민감하므로 heatmap이 실제 스크래치인지 반사인지 구분하는 것이 중요하다.

| 항목 | 판정/점검 기준 |
| --- | --- |
| 카테고리 특성 | 중앙 구멍, 외곽 형태, 금속 표면 반사가 판정에 큰 영향을 준다. |
| 주요 결함 유형 | 스크래치, 찍힘, 변형, 색상 이상, 방향 이상, 오염 |
| 우선 확인 위치 | 구멍 주변, 외곽 경계, 금속 표면, 색상 변화 부위 |
| 재검사 조건 | 금속 반사로 보이는 넓은 heatmap 또는 원본에서 결함이 불명확한 경우 |
| 불량 의심 조건 | 구멍 주변 변형, 외곽 파손, 표면 스크래치 위치에 heatmap이 반복 집중되는 경우 |
| 오탐 가능 원인 | 금속 반사, 조명 방향 변화, 그림자, 회전/방향 차이 |
| 작업자 점검 | 구멍 내부/외부 경계와 금속 표면을 확대 확인하고, 반사 여부를 재촬영으로 검토한다. |
| Heatmap 위치 | 가능 해석 | 확인 조치 |
| --- | --- | --- |
| 구멍 주변 | 변형, 찍힘, 오염 가능성 | 구멍 내부/외부 경계 확인 |
| 외곽 경계 | 형태 변형, 외곽 손상, 방향 차이 | 정상 샘플과 외곽 비교 |
| 금속 표면 선형 영역 | 스크래치 또는 반사 가능성 | 조명 각도 확인 후 재촬영 |
| 색상 변화 부위 | 오염, 변색, 조명 영향 가능성 | 원본 확대 및 조명 상태 확인 |

## 6. 재검사 및 불량 의심 조건

### 6.1 기본 판정 기준

카테고리별 판단 기준과 별개로, 다음 조건은 object 계열 전체에서 재검사 또는 불량 의심 판단에 참고한다. 정확한 threshold 값은 모델 버전, 카테고리, 검증 데이터에 따라 달라지므로 본 문서에서 숫자로 고정하지 않는다.

| 구분 | 조건 | 작업자 조치 |
| --- | --- | --- |
| 정상 처리 가능 | score가 낮고 heatmap이 약하거나 원본에서 결함이 보이지 않음 | 정상 처리 가능. 단, 반복 이력은 결과 화면에서 확인한다. |
| 재검사 권장 | score가 중간이거나 heatmap이 국소적으로 나타나지만 원본 결함이 불명확함 | 동일 조건으로 재촬영하고 정상 샘플과 비교한다. |
| 불량 의심 | score가 높고 카테고리별 결함 위치에 heatmap이 명확하게 집중됨 | 후속 확인 또는 불량 의심 대상으로 등록한다. |

불량 의심은 자동 확정 불량을 의미하지 않는다. 작업자는 원본 이미지, heatmap 위치, 재검사 결과를 함께 확인한 뒤 후속 확인 또는 불량 의심 등록 여부를 결정한다.

본 문서에서 사용하는 score 낮음/중간/높음, heatmap 약함/국소 집중/넓게 분산 등의 표현은 모델 실험 결과 확정 전 사용하는 정성적 해석 표현이다. 실제 운영 단계의 threshold 및 정량 기준은 모델 버전, 카테고리별 검증 결과에 따라 별도 설정하며, 자세한 기준은 `Heatmap_AnomalyMap_해석가이드_v1` 및 `정상_재검사_불량_판정기준서_v1`에서 다룬다.

### 6.2 추가 상태/사유

| 추가 상태/사유 | 의미 | 작업자 조치 |
| --- | --- | --- |
| 저신뢰 | heatmap이 넓게 퍼지거나 조명/초점/위치 변화가 의심됨 | 설비 상태 확인 후 재촬영한다. |
| 반복 감지 | 재검사에서도 동일 위치에 heatmap이 반복됨 | 실제 결함 가능성이 높으므로 결과 기록 및 후속 확인을 수행한다. |
| 촬영 조건 의심 | 조명 반사, 초점 흐림, 위치 변화, 배경 변화가 결과에 영향을 준 것으로 보임 | 촬영 조건을 조정한 뒤 동일 조건으로 재촬영한다. |

## 7. 오탐 및 미탐 방지 유의사항

Object 계열은 제품 위치, 회전, 촬영 각도 차이만으로도 제품 경계 부근에 heatmap이 나타날 수 있다.

금속 표면이나 유광 재질은 조명 반사로 인해 score가 높아질 수 있다.

cable처럼 형태 변화가 큰 카테고리는 정상 배치 차이와 실제 결함을 구분해야 한다.

capsule처럼 작은 object는 먼지, 압축 노이즈, 초점 문제로 국소 heatmap이 발생할 수 있다.

hazelnut처럼 자연물 형태를 가진 카테고리는 정상 형태 변동과 실제 결함을 정상 샘플과 비교해야 한다.

문서에 없는 원인은 단정하지 않고 원본 이미지, heatmap, 재검사 결과를 함께 확인한다.

원본 이미지에서 깨짐, 균열, 찍힘, 오염이 육안으로 보이지만 score가 낮거나 heatmap이 약한 경우에는 미탐 가능성이 있으므로 정상으로 단정하지 않는다.

미탐이 의심되는 결과는 원본 이미지, heatmap, 재촬영 결과를 함께 기록하고 후속 확인 대상으로 기록한다.

## 9. 관리자 참고: 카테고리별 성능 해석

관리자는 모델 실험에서 object 평균 성능을 계산하는 경우, 본 프로젝트의 object 평균을 MVTec AD 전체 object 10개가 아니라 프로젝트 초기 실험에서 선택한 5개 object 카테고리 기준으로 해석한다. 카테고리별 성능 편차가 클 수 있으므로 전체 평균만으로 모델을 판단하지 않고, category별 Image-level AUROC, Pixel-level AUROC, PRO, F1-score를 함께 확인한다.

| 지표 | 카테고리별 해석 기준 |
| --- | --- |
| Image-level AUROC | 각 object 카테고리에서 정상/이상 이미지를 얼마나 잘 구분하는지 확인한다. |
| Pixel-level AUROC | 카테고리별 heatmap이 실제 결함 위치를 얼마나 잘 가리키는지 확인한다. |
| PRO | 결함 영역 단위로 위치 탐지 품질을 확인한다. 작은 결함이 많은 카테고리에서 중요하다. |
| F1-score | threshold 적용 후 정상/불량 의심 판정 균형을 확인한다. 오탐/미탐 조정에 활용한다. |
| Worst Category 또는 최저 성능 카테고리 | 선택 지표로 사용하며, 가장 성능이 낮은 object 카테고리를 확인하여 운영 리스크를 판단한다. |
