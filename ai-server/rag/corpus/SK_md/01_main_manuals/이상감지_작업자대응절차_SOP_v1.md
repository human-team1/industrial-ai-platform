# 이상감지 작업자대응절차 SOP

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 이상감지 결과가 발생했을 때 현장 작업자가 따라야 하는 표준 대응 절차를 설명하기 위한 SOP 문서이다.

본 프로젝트는 이미지 기반 이상탐지 모델을 통해 anomaly score, 정상/재검사/불량 의심 판정, heatmap/anomaly map을 제공한다. 작업자는 모델 결과를 확정 판정으로 단정하지 않고 원본 이미지, heatmap 위치, 재촬영 결과, 설비 상태를 함께 확인해야 한다.

이 문서는 이상 발생 시 원본 확인, 재촬영, 설비 점검, 후속 확인 대상 기록, 결과 기록까지의 공통 절차를 제공하며, RAG 기반 문서 질의응답과 작업자 대응 절차 추천의 근거 문서로 사용한다.

## 2. 적용 범위

| 항목 | 내용 |
| --- | --- |
| 데이터셋 | MVTec AD |

| 관련 결과 | anomaly score, image-level 판정, heatmap/anomaly map, result artifact |

설비 점검이 필요한 경우 작업자는 보고 필요 항목으로 기록하며, 필요 시 현장 설비 점검 담당자와 협의하여 카메라, 조명, 센서, 컨베이어 상태를 확인할 수 있다.

본 문서는 모델 threshold 수치를 정의하는 문서가 아니라, 이상감지 결과가 발생했을 때 작업자가 어떤 순서로 확인하고 조치할지 정의하는 운영형 절차서이다.

## 3. SOP 적용 트리거

작업자는 아래 상황이 발생하면 본 SOP를 적용한다. score와 heatmap 강도 표현은 정성적 해석 표현이며, 실제 threshold 기준은 모델 버전과 카테고리별 검증 결과에 따라 별도로 관리한다.

| 트리거 상황 | 의미 | 기본 대응 |
| --- | --- | --- |
| 재검사 판정 | score가 경계 구간이거나 원본 결함이 불명확한 상태 | 동일 조건으로 재촬영하고 정상 샘플과 비교한다. |
| 불량 의심 판정 | score가 높고 결함 위치에 heatmap이 명확하게 집중되는 상태 | 원본 확대 확인 후 후속 확인 대상으로 기록한다. |
| 저신뢰 결과 또는 저신뢰 상태 | 조명, 초점, ROI, 제품 위치 문제로 결과 신뢰도가 낮은 상태 | 촬영 조건과 설비 상태를 점검한 뒤 재촬영한다. |
| 동일 위치 반복 감지 | 재검사 또는 반복 촬영에서도 유사 위치에 heatmap이 반복되는 상태 | 실제 결함 가능성이 높으므로 결과를 기록하고 후속 확인을 수행한다. |
| 작업자 육안 판단과 불일치 | 모델 결과와 작업자 육안 판단이 서로 다른 상태 | 원본, heatmap, 정상 샘플을 함께 확인하고 필요 시 후속 확인을 요청한다. |
| 오탐/미탐 의심 | 정상으로 보이는 이미지가 불량 의심으로 나오거나, 원본에서 결함이 보이는데 모델 반응이 약한 상태 | 원본, heatmap, 정상 샘플, 촬영 조건을 확인하고 후속 확인을 요청한다. |

## 6. 단계별 작업자 대응 절차

### 6.1 결과 확인

- 검사 카테고리가 실제 입력 이미지와 일치하는지 확인한다.

- anomaly score와 정상/재검사/불량 의심 판정 결과를 확인하고, 저신뢰 등 추가 상태가 표시되었는지 확인한다.

- result artifact에 원본 이미지와 heatmap/anomaly map이 정상 저장되었는지 확인한다.

### 6.2 원본 이미지 확인

- 원본 이미지를 확대하여 결함 후보 위치가 육안으로 확인되는지 확인한다.

- 정상 샘플과 비교하여 제품 형태, 표면 패턴, 색상, 위치 차이를 확인한다.

- 먼지, 일시적 그림자, 압축 노이즈처럼 실제 결함이 아닌 요인을 구분한다.

### 6.3 Heatmap / Anomaly Map 확인

- heatmap이 원본 이미지의 실제 결함 후보 위치와 일치하는지 확인한다.

- object 계열은 제품 경계, 연결부, 구멍 주변, 표면 손상 부위를 우선 확인한다.

- texture 계열은 스크래치, 얼룩, 균열, 패턴 깨짐, 질감 변화 부위를 우선 확인한다.

- heatmap은 확정 불량 위치가 아니라 점검 우선 영역으로 해석한다.

### 6.4 재촬영 및 재검사

- 원본 결함이 불명확하거나 저신뢰 판정이면 동일 조건으로 재촬영한다.

- 재촬영 시 카메라 위치, 조명 조건, 제품 위치가 기존 검사와 동일한지 확인한다.

- 재검사에서도 동일 위치에 heatmap이 반복되면 반복 감지 추가 상태로 기록하고 후속 확인 대상으로 기록한다.

### 6.5 설비 및 촬영 조건 점검

- 저신뢰 판정, 넓게 퍼진 heatmap, 반복 오탐이 발생하면 카메라, 조명, ROI, 제품 위치, 센서/trigger 상태를 확인한다.

- 렌즈 오염, 초점 흐림, 조명 반사, 그림자, 제품 위치 흔들림이 있는지 점검한다.

- 설비 문제로 판단되면 보고 필요 항목으로 기록하고, 필요 시 현장 설비 점검 담당자와 협의하여 조치한다.

### 6.6 후속 확인 및 전달

- 불량 의심 판정, 동일 위치 반복 감지, 작업자 판단과 모델 결과 불일치가 발생하면 후속 확인 대상으로 기록하고 필요한 정보를 전달한다.

- 검토 요청 시 검사 ID, 카테고리, anomaly score, heatmap 위치, 원본 확인 결과, 재검사 결과를 함께 전달한다.

- 작업자는 관리자 권한과 승인 절차 없이 threshold 또는 모델 설정을 변경하지 않는다.

### 6.7 결과 기록

- 최종 조치 결과, 추정 결함 유형, 오탐/미탐 의심 원인, 재촬영 여부, 재검사 결과를 기록한다.

- 동일 위치 반복 감지나 후속 확인 요청이 발생한 경우 관련 이미지와 heatmap 결과를 함께 보관한다.

## 7. 상황별 대응 기준

| 상황 | 작업자 확인 | 권장 조치 |
| --- | --- | --- |
| score 높음 + heatmap 국소 집중 | 원본 결함과 heatmap 위치가 일치하는지 확인 | 후속 확인 또는 불량 의심 대상으로 등록한다. |
| score 높음 + heatmap 넓게 분산 | 조명, 초점, 배경, ROI, 제품 위치 변화 확인 | 촬영 조건 점검 후 재촬영한다. |
| score 낮음 + 원본 결함 의심 | 원본 이미지의 결함 후보가 명확한지 확인 | 재검사 또는 후속 확인을 요청한다. |
| 재검사에서도 동일 위치 반복 감지 | 이전 결과와 heatmap 위치를 비교 | 반복 감지 추가 상태로 기록하고 후속 확인을 요청한다. |
| 저신뢰 상태 + 이미지 품질 문제 | 초점 흐림, motion blur, 조명 불균형 확인 | 설비 상태 확인 후 동일 조건으로 재촬영한다. |
| 작업자 판단과 모델 결과 불일치 | 원본, heatmap, 정상 샘플, 재검사 결과를 함께 확인 | 후속 확인 요청 및 사례 기록을 수행한다. |
| 재검사 판정 | score가 경계 구간이거나 heatmap은 있으나 원본 결함이 불명확한지 확인 | 동일 조건으로 재촬영하고 정상 샘플과 비교한다. 재검사에서도 동일 위치가 반복되면 후속 확인을 요청한다. |

## 8. 설비 및 촬영 조건 점검 체크리스트

| 조명 | 밝기 불균형, 반사, 그림자, 과노출/저노출 여부 | 조명 각도/밝기 조정 후 재촬영 |
| 제품 위치 | 제품 회전, 기울어짐, ROI 밖 이동, 정렬 불량 여부 | 제품 위치 정렬 후 재검사 |

| 컨베이어/이송 | 제품 흔들림, 속도 변화, 정지 위치 편차 여부 | 이송 조건 확인 및 보고 필요 |
| 센서/Trigger | 제품 감지 실패, trigger 지연, 중복 촬영 여부 | 센서 상태와 trigger 로그 확인 |
| 시스템 | 모델 버전, threshold 설정 정보, 결과 저장 여부 | 모델 버전, threshold 설정 정보, result artifact 저장 여부를 확인하고 이상 시 관리자에게 문의한다. |

## 9. 후속 확인 및 에스컬레이션 기준

작업자는 다음 조건에 해당하는 경우 후속 확인 대상으로 기록하고 필요한 정보를 전달한다.

| 검토 요청 조건 | 이유 | 요청 시 포함할 정보 |
| --- | --- | --- |
| 불량 의심 판정 | 실제 결함 가능성이 높고 최종 처리 결정이 필요함 | 검사 ID, 카테고리, score, heatmap 위치, 원본 확인 결과 |
| 동일 위치 반복 감지 | 일시적 촬영 문제가 아니라 실제 결함일 가능성이 증가함 | 재검사 전후 이미지와 heatmap 비교 결과 |
| 오탐/미탐 의심 | 모델 또는 촬영 조건 개선 검토가 필요함 | 오탐/미탐 의심 원인, 촬영 조건, 정상 샘플 비교 결과 |
| 저신뢰 반복 발생 | 설비 상태 또는 입력 품질 문제가 반복될 가능성이 있음 | 발생 시간대, 카메라/조명 상태, 재촬영 결과 |
| 작업자 판단 불일치 | 모델 결과와 현장 판단 차이에 후속 확인이 필요함 | 원본 이미지, heatmap, 작업자 확인 의견 |

## 10. 결과 기록 항목

| 모델 버전 | 해당 판정을 생성한 모델명 또는 model version |
| threshold 설정 정보 | 적용된 threshold 버전, threshold profile, 또는 설정 파일 ID |
| anomaly score | 모델이 산출한 이상 점수 |
| 판정 결과 | 정상, 재검사, 불량 의심 |
| 추가 상태 | 저신뢰, 반복 감지, 촬영 조건 의심 등 추가 상태 또는 사유 |
| heatmap 집중 위치 | 제품 경계, 연결부, 구멍 주변, 반복 패턴, 스크래치 부위, 균열선 등 |
| 추정 결함 유형 | object: 형태 변형/깨짐/오염/연결 이상 등, texture: 스크래치/오염/균열/패턴 깨짐 등 |
| 원본 확인 결과 | 실제 결함 확인 여부 |
| 오탐/미탐 의심 원인 | 조명 반사, 초점 흐림, 위치 변화, 정렬 차이, 자연 질감 변화 등 |
| 재촬영 여부 | 동일 조건 재촬영 수행 여부 |
| 재검사 결과 | 재촬영 후 정상/재검사/불량 의심 중 확인된 판정 결과와 추가 상태 |
| 최종 조치 | 정상 처리, 재검사, 후속 확인, 불량 의심 등록 |

## 11. 작업자 주의사항

- 불량 의심은 자동 확정 불량을 의미하지 않는다. 원본 이미지, heatmap 위치, 재검사 결과를 함께 확인한다.

- heatmap은 확정 불량 위치가 아니라 점검 우선 영역으로 해석한다.

- score가 높더라도 조명, 초점, 위치 변화, ROI 문제로 인한 오탐 가능성이 있다.

- score가 낮더라도 원본 이미지에서 명확한 결함이 보이면 재검사 또는 후속 확인을 요청한다.

- threshold 변경이나 모델 설정 변경은 작업자가 임의로 수행하지 않으며, 관리자 승인 절차를 거친다.

- 문서에 없는 원인은 단정하지 않고 결과 기록과 후속 확인을 통해 확인한다.

## 12. 예상 질문

1. 이상감지 결과가 나오면 작업자는 가장 먼저 무엇을 확인해야 하나?

2. 재검사 판정이 나오면 어떤 순서로 대응해야 하나?

3. 불량 의심 판정은 바로 불량 확정을 의미하나?

4. heatmap이 넓게 퍼지면 어떤 촬영 조건을 확인해야 하나?

5. 재촬영 후에도 같은 위치에 heatmap이 반복되면 어떻게 해야 하나?

6. 작업자 육안 판단과 모델 결과가 다르면 어떻게 처리해야 하나?

7. 저신뢰 결과가 반복되면 어떤 설비 항목을 점검해야 하나?

8. 오탐 또는 미탐이 의심될 때 어떤 정보를 기록해야 하나?

9. 후속 확인 요청 시 어떤 정보를 포함해야 하나?

10. 작업자가 threshold나 모델 설정을 직접 변경해도 되나?
