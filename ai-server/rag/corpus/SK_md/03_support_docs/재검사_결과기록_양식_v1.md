# 재검사 결과기록 양식

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 재검사 판정이 발생했을 때 누가, 언제, 무엇을 확인했는지 기록하기 위한 운영형 양식 문서이다.

재검사는 anomaly score가 경계 구간에 있거나 heatmap은 나타났지만 원본 결함이 명확하지 않은 경우, 또는 입력 이미지 품질과 촬영 조건을 다시 확인해야 하는 경우 수행한다.

이 문서는 재검사 발생 조건, 재검사 수행 절차, 결과 기록 항목, 후속 확인 기준을 제공하며 RAG 기반 문서 질의응답과 결과 이력 추적의 근거 문서로 사용한다.

## 2. 적용 범위

| 항목 | 내용 |
| --- | --- |
| 데이터셋 | MVTec AD |
| 대상 상황 | 재검사 판정, 저신뢰 결과, score/heatmap 경계 사례, 작업자 육안 판단과 모델 결과 불일치 |
| 적용 카테고리 | object 5개 및 texture 5개 전체 |

| 관련 결과 | anomaly score, image-level 판정, heatmap/anomaly map, result artifact, 재검사 결과 |
| 관련 사용자 | 현장 작업자, 관리자 |

본 문서는 재검사를 수행한 사실과 확인 내용을 기록하는 양식이며, threshold 수치 자체를 정의하지 않는다.

## 3. 재검사 발생 조건

| 발생 조건 | 의미 | 재검사 목적 |
| --- | --- | --- |
| 재검사 판정 | score가 경계 구간이거나 heatmap은 있으나 원본 결함이 불명확한 상태 | 동일 조건 재촬영을 통해 일시적 촬영 문제인지 실제 결함인지 확인한다. |
| 저신뢰 결과 | 조명, 초점, ROI, 제품 위치 문제로 결과 신뢰도가 낮은 상태 | 촬영 조건을 보정한 뒤 결과가 안정되는지 확인한다. |
| score 낮음 + 원본 결함 의심 | 모델 반응은 약하지만 작업자가 원본에서 결함 후보를 확인한 상태 | 미탐 가능성을 줄이기 위해 후속 확인 또는 재검사를 수행한다. |
| score 높음 + heatmap 넓게 분산 | 촬영 조건 문제 또는 배경/조명 영향 가능성이 있는 상태 | 조명, 초점, 위치, ROI를 확인한 뒤 재촬영한다. |
| 작업자 판단과 모델 결과 불일치 | 모델 판정과 작업자 육안 판단이 서로 다른 상태 | 원본, 정상 샘플, heatmap, 재검사 결과를 함께 비교한다. |

## 4. 재검사 수행 절차

| 순서 | 단계 | 수행 내용 | 기록 항목 |
| --- | --- | --- | --- |
| 1 | 최초 결과 확인 | 검사 ID, 카테고리, anomaly score, 판정 결과, heatmap 위치를 확인한다. | 검사 ID, 최초 판정, 최초 score |
| 2 | 원본 이미지 확인 | 원본 이미지를 확대하여 실제 결함 후보가 보이는지 확인한다. | 원본 확인 결과, 추정 결함 유형 |
| 3 | 촬영 조건 확인 | 조명 반사, 초점 흐림, ROI 누락, 제품 위치 변화가 있는지 확인한다. | 오탐/미탐 의심 원인 |
| 4 | 동일 조건 재촬영 | 가능한 한 최초 검사와 동일한 위치, 조명, 카메라 조건에서 재촬영한다. | 재촬영 여부, 재촬영 시간 |
| 5 | 재검사 결과 비교 | 최초 결과와 재검사 결과의 score, heatmap 위치, 판정을 비교한다. | 재검사 score, 재검사 판정, 반복 감지 여부 |
| 6 | 후속 확인 판단 | 동일 위치 반복 감지가 확인되거나, 불량 의심 또는 모델 결과 불일치가 있으면 후속 확인을 요청한다. | 후속 확인 요청 여부, 요청 사유 |
| 7 | 최종 기록 | 최종 조치와 재검사 결과를 기록하고 result artifact를 보관한다. | 최종 조치, 비고 |

## 5. 재검사 결과 기록 양식

아래 표는 재검사 발생 시 작성해야 하는 기본 기록 항목이다. 실제 시스템에서는 같은 항목을 화면 입력 폼, CSV, JSON 또는 운영 DB에 저장할 수 있다.

| 기록 항목 | 작성 내용 |
| --- | --- |
| 검사 ID | 최초 검사 결과를 식별하기 위한 ID |
| 재검사 ID | 재검사 결과를 식별하기 위한 ID. 최초 검사 ID와 연결한다. |
| 검사 일시 | 최초 검사와 재검사가 수행된 날짜와 시간 |
| 작업자 | 재검사를 수행한 작업자 이름 또는 ID |
| 카테고리 | bottle, cable, capsule, hazelnut, metal_nut, carpet, grid, leather, tile, wood 중 해당 카테고리 |
| 모델 버전 | 최초 검사와 재검사에 적용된 모델명 또는 model version |
| threshold 설정 정보 | 적용된 threshold 버전, threshold profile, 또는 설정 파일 ID |
| 최초 anomaly score | 최초 검사에서 산출된 이상 점수 |
| 최초 판정 결과 | 정상, 재검사, 불량 의심 중 최초 판정 |
| 최초 heatmap 집중 위치 | 최초 검사에서 heatmap이 집중된 위치 |
| 재검사 anomaly score | 재검사에서 산출된 이상 점수 |
| 재검사 판정 결과 | 재검사 후 정상, 재검사, 불량 의심 중 확인된 결과 |
| 추가 상태/사유 | 저신뢰, 반복 감지, 촬영 조건 의심 등 필요 시 기록 |
| 재검사 heatmap 집중 위치 | 재검사에서 heatmap이 집중된 위치 |
| 재검사 전후 비교 결과 | score 증가/감소, heatmap 위치 동일/변경/소실, 판정 변경 여부를 기록한다. |
| 반복 감지 여부 | 최초 검사와 재검사에서 유사 위치에 heatmap이 반복되었는지 여부 |
| 추정 결함 유형 | object: 형태 변형/깨짐/오염/연결 이상 등, texture: 스크래치/오염/균열/패턴 깨짐 등 |
| 원본 확인 결과 | 작업자가 원본 이미지에서 실제 결함을 확인했는지 여부 |
| 오탐/미탐 의심 원인 | 조명 반사, 초점 흐림, 위치 변화, 정렬 차이, 자연 질감 변화 등 |
| 최종 조치 | 정상 처리, 추가 재검사, 후속 확인, 불량 의심 등록 |
| 첨부 자료 | 최초 원본 이미지, 최초 heatmap, 재검사 원본 이미지, 재검사 heatmap, 결과 JSON/CSV 파일 |
| 비고 | 특이사항, 후속 요청 사항, 설비 점검 필요 여부 |

## 6. 재검사 결과 해석 기준

| 재검사 결과 | 해석 | 권장 조치 |
| --- | --- | --- |
| 동일 위치 heatmap 반복 | 일시적 촬영 문제가 아니라 실제 결함일 가능성이 증가함 | 후속 확인 또는 불량 의심 대상으로 등록한다. |
| 재검사 후 heatmap 사라짐 | 초기 결과가 조명, 위치, 초점 등 일시적 요인일 가능성 있음 | 정상 처리 가능하나 반복 이력은 기록한다. |
| heatmap 위치 변경 | 촬영 조건, 제품 위치, ROI 영향 가능성 있음 | 촬영 조건과 ROI를 확인한 뒤 필요 시 추가 재촬영한다. |
| score는 낮지만 원본 결함 명확 | 미탐 가능성이 있음 | 후속 확인을 요청한다. |
| 저신뢰 반복 | 설비 또는 입력 이미지 품질 문제가 반복될 가능성 있음 | 카메라, 조명, 센서/trigger, ROI 상태를 점검하고 필요 시 보고 필요로 기록한다. |

## 7. 후속 확인 기준

재검사에서도 동일 위치에 heatmap이 반복되는 경우

작업자 육안으로 결함이 명확하지만 score가 낮거나 heatmap 반응이 약한 경우

불량 의심 판정이 반복되지만 원본 결함이 명확하지 않은 경우

저신뢰 결과가 같은 설비 또는 같은 시간대에서 반복되는 경우

모델 버전 또는 threshold 설정 정보가 예상과 다르거나 변경 이력이 불명확한 경우

원본 이미지, heatmap, anomaly map, 결과 JSON/CSV 등 result artifact가 누락되었거나 서로 연결되지 않는 경우
