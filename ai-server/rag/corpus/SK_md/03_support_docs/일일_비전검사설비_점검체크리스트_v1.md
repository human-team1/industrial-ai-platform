# 일일 비전검사설비 점검체크리스트

샘플 매뉴얼 v1

산업 이미지 이상탐지 프로젝트 - RAG/LLM 문서셋

## 1. 문서 목적

본 문서는 산업 이미지 이상탐지 프로젝트에서 작업 시작 전 현장 작업자가 수행해야 하는 비전검사 설비 점검 항목을 정리하기 위한 체크리스트 문서이다.

본 프로젝트는 이미지 기반 이상탐지 모델을 통해 anomaly score, 정상/재검사/불량 의심 판정, heatmap/anomaly map을 제공한다. 안정적인 검사 결과를 얻기 위해서는 모델 실행 전 카메라, 조명, 제품 위치, ROI, 컨베이어, 센서/trigger, 결과 저장 상태를 점검해야 한다.

이 문서는 일일 점검 절차, 이상 발견 시 조치 기준, 점검 결과 기록 항목을 제공하며, RAG 기반 문서 질의응답과 작업자 점검 안내의 근거 문서로 사용한다.

## 2. 적용 범위

| 항목 | 내용 |
| --- | --- |
| 데이터셋 | MVTec AD |

| 관련 설비 | 카메라, 렌즈, 조명, 제품 위치 정렬, ROI/crop, 컨베이어, 센서/trigger, 결과 저장 시스템 |

설비 점검이 필요한 경우 작업자는 보고 필요 항목으로 기록하며, 필요 시 현장 설비 점검 담당자와 협의하여 카메라, 조명, 센서, 컨베이어 상태를 확인할 수 있다.

본 문서는 설비의 정기 유지보수 매뉴얼을 대체하지 않는다. 작업 시작 전 검사 품질에 직접 영향을 주는 항목을 빠르게 확인하기 위한 운영형 체크리스트이다.

| 결과 저장 실패 | 저장 경로 오류, 권한 문제, result artifact 누락 | 저장 경로와 파일 생성 여부 확인 | 결과 파일 누락이 반복되거나 이력 추적이 불가능한 경우 |
| 모델/threshold 정보 불일치 | 모델 버전 오적용, 설정 파일 변경, threshold profile 오류 | 작업자는 임의 변경하지 않고 관리자에게 문의하며, 관리자는 변경 이력과 적용 범위를 확인한다. | 설정 정보가 예상과 다르거나 변경 이력이 불명확한 경우 |

| 조치 내용 | 청소, 재촬영, 조명 조정, ROI 확인, 보고 필요 등 수행한 조치 |

| 점검 결과 상태 | 전체 점검 결과 요약. 정상 / 이상 / 확인 필요 중 선택 |
| 재촬영 여부 | 점검 후 기준 샘플 또는 정상 제품을 재촬영했는지 여부 |
| 보고 여부 | 보고 필요로 기록했는지 여부 |
| 비고 | 반복 발생, 미처리 사항, 교대 시 전달 필요 사항 |

점검 결과는 단순히 정상/이상으로만 기록하지 않고, 조치 완료, 보고 필요, 인수인계 필요 여부까지 함께 기록한다. 이는 교대 근무 시 미처리 점검 항목이 누락되지 않도록 하기 위한 것이다.

## 7. 점검 완료 기준

카메라와 조명 상태가 정상이고, 기준 샘플 이미지에서 초점 흐림이나 과도한 반사가 확인되지 않는다.

검사 대상이 ROI 안에 안정적으로 포함되고, 제품 위치 변화로 인한 경계 오탐 가능성이 낮다.

센서/trigger가 정상 동작하며 제품 진입 시 결과가 정상적으로 생성된다.

원본 이미지, heatmap/anomaly map, 결과 파일이 지정된 위치에 저장된다.

모델 버전과 threshold 설정 정보가 운영 기준과 일치한다.

이상 항목이 있을 경우 조치 내용과 보고 필요 여부가 기록된다.

실제 설비별 상세 점검 기준은 사용 중인 카메라, 조명, 컨베이어, 센서 제조사 매뉴얼과 현장 운영 기준을 함께 참고한다.

점검 결과가 반복적으로 이상으로 기록되는 경우 이상감지_작업자대응절차_SOP_v1 및 오탐_미탐_발생보고서_양식_v1에 따라 후속 조치를 수행한다.
