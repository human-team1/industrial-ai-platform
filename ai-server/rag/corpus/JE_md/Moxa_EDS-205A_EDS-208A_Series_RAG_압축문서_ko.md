이 문서는 Moxa EDS-205A/208A Series 현장 운용 중 발생할 수 있는 전원 미인가, 링크 단절, 통신 불안정, 브로드캐스트 폭주, 광 포트 연결 문제를 빠르게 확인하기 위한 RAG 검색용 압축 문서이다. (출처: moxa-eds-208a-series-qig-v8.2.pdf, p.2-17)

# 4. 주요 증상

| **증상**                                     | **현장 해석**                                                                                 | **주요 출처**  |
|----------------------------------------------|-----------------------------------------------------------------------------------------------|----------------|
| P1 또는 P2 LED가 꺼짐                        | Power input P1/P2에 전원이 공급되지 않거나 DC 입력 배선/전원원이 불안정할 수 있다.            | p.11, p.13     |
| 10M/100M LED가 꺼짐                          | TP 또는 FX 포트 링크가 비활성 상태이다. 케이블, 상대 장비, 포트, 속도 협상 상태를 확인한다.   | p.13-p.14      |
| 통신이 간헐적으로 끊김                       | 전원 배선과 통신 배선이 같은 경로로 배치되어 EMI 영향을 받거나 접지가 부족할 수 있다.         | p.10           |
| 브로드캐스트 트래픽으로 네트워크가 느림      | Broadcast Storm Protection(BSP)이 비활성화되어 있을 수 있다.                                  | p.13           |
| 광 포트(FX) 연결 불가                        | SC/ST 광 케이블의 Tx/Rx 방향이 맞지 않거나 단거리 단일모드에서 광 파워가 과도할 수 있다.      | p.12, p.15     |
| DIP 설정 변경 후 동작이 안 바뀜              | DIP Switch 변경 후 전원 OFF/ON을 수행하지 않아 설정이 반영되지 않았을 수 있다.                | p.13           |
| 장비 표면이 뜨겁거나 위험 구역에서 작업 필요 | Restricted Access Location 및 HOT SURFACE 경고, Class I Division 2/ATEX 조건 확인이 필요하다. | p.9-p.10, p.17 |

# 6. 점검 순서

1.  전원 차단 상태에서 제품 라벨의 정격 전압과 실제 DC 전원 전압을 확인한다. (p.10-p.11)

2.  P1/P2 단자대의 V+/V- 배선, 체결 상태, 중복 전원 입력 여부를 확인한다. (p.11, p.13)

3.  접지 나사(Grounding screw)에서 접지면으로 접지 연결이 되어 있는지 확인한다. (p.10)

4.  10/100BaseT(X) 포트의 10M/100M LED가 켜짐/점멸/꺼짐 중 어떤 상태인지 확인한다. (p.13-p.14)

5.  RJ45 케이블, 상대 장비 포트, auto MDI/MDI-X 조건을 확인한다. (p.12, p.14)

6.  광 포트 모델은 SC/ST Tx와 Rx가 상대 장비와 교차 연결되어 있는지 확인한다. (p.12-p.13)

7.  브로드캐스트 폭주가 의심되면 DIP Switch의 BSP 상태를 확인한다. (p.13)

8.  DIP 설정을 바꾼 뒤에는 반드시 장비 전원을 껐다 켜서 설정을 반영한다. (p.13)

9.  고온 표면, 위험 장소, ATEX/Class I Division 2 환경에서는 전원 인가 상태 분리 작업을 금지한다. (p.9-p.10, p.17)

# 7. 조치 방법

| **상황**                          | **조치 방법**                                                                                                                     | **출처**  |
|-----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|-----------|
| P1/P2 전원 미인가                 | DC 전원 안정화 후 V+/V-를 다시 체결하고 터미널 블록을 확실히 삽입한다.                                                            | p.11      |
| 통신 링크 없음                    | RJ45 케이블과 상대 장비를 교체/확인하고 10M/100M LED가 켜지는지 확인한다. Auto MDI/MDI-X로 직결/크로스 케이블 모두 사용 가능하다. | p.12-p.14 |
| 광 링크 없음                      | SC/ST 케이블의 Tx를 상대 Rx에, Rx를 상대 Tx에 연결한다. 케이블 양 끝을 A-A, B-B처럼 라벨링한다.                                   | p.12-p.13 |
| 브로드캐스트 폭주                 | DIP Switch BSP를 ON으로 설정하고 장비를 power off/on 한다.                                                                        | p.13      |
| 통신 노이즈                       | 전원선과 통신선을 분리 배선하고, 교차 시 직각으로 배치한다. 접지 나사를 접지면에 연결한다.                                        | p.10      |
| 주소 테이블/네트워크 변경 후 이상 | 주소 버퍼 초기화를 위해 장비를 power down 후 power up 한다.                                                                       | p.14      |
| 위험 구역 작업                    | 회로가 live 상태이면 장비를 분리하지 않는다. 점화성 농도가 없는 것으로 확인된 경우에만 작업한다.                                  | p.9-p.10  |

# 8. 재검사/관리자 검토 조건

조치 후 P1/P2 LED가 켜지고, 10M/100M LED가 켜짐 또는 점멸 상태인지 확인한다. DIP 변경은 전원 재기동 후 재확인한다. 반복적으로 전원 LED가 꺼지거나 포트 LED가 비활성 상태이면 전원 품질, 케이블, 상대 장비, 환경 조건을 관리자에게 보고한다.

# 9. 오탐 또는 주의사항

- Moxa EDS는 plug-and-play 장비이므로 일반 설치/유지보수 시 소프트웨어 설정이 필요 없다는 점을 오인하지 않는다. (p.14)

- 비협상(non-negotiating) 장비와 연결하면 RJ45 포트가 10 Mbps half-duplex로 동작할 수 있다. 이는 고장이 아닐 수 있다. (p.15)

- BSP DIP 기본값은 OFF이며, ON으로 바꿔도 전원 재기동 전에는 반영되지 않는다. (p.13)

- Class 1 Laser/LED 제품의 광 포트를 직접 바라보지 않는다. (p.13)

- 이 문서는 보증, 회사 연락처, 전체 인증 목록을 RAG 본문에서 제외하고 현장 점검 중심으로 압축했다.
