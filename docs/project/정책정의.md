
# 1. 문서 개요

본 문서는 산업 이상 탐지 시스템의 기능이 어떤 규칙과 기준으로 동작해야 하는지를 정의한다.

정책 정의는 기능 명세, 사용자 권한, 화면 설계, API 동작, 예외 처리, 운영 기준의 근거로 활용한다.

본 문서에서의 권한 기준은 다음과 같다.

## 1. 문서 개요

본 문서는 산업 이상 탐지 시스템의 기능이 어떤 규칙과 기준으로 동작해야 하는지를 정의한다.

정책 정의는 기능 명세, 사용자 권한, 화면 설계, API 동작, 예외 처리, 운영 기준의 근거로 활용한다.

본 문서에서의 권한 기준은 다음과 같다.

- **일반 사용자**: 검사 수행, 결과 조회, 챗봇 사용, 자기 회사 문서 관리, 허용 범위 내 임계값 설정, 자기 알림 및 자기 챗봇 이력 조회 수행
- **시스템 관리자(사이트 운영자)**: 운영 모니터링, 감사 로그 조회, 전체 데이터 조회, 가입 승인/거절, 재검토 처리, 보고서 조회, 회사 관리, 임계값 정책 관리 수행
- **시스템**: 검사 처리, 문서 인덱싱, 보고서 생성, 저장/이력/추적 자동 처리 수행
