
- **관리자 = 사이트 운영자**
- **임계값 설정 = 일반 사용자 기능**
- **회원가입은 구글 연동 기반 신청 + 사이트 운영자 승인**
- **실시간 탐지 / 업로드 탐지 분리**
- **챗봇은 문서 질의응답, 결과 설명, 대응 절차, 히스토리까지 포함**
- **운영 모니터링 / 감사 로그 / 가입 승인**
