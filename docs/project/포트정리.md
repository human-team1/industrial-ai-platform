# 포트 정리

로컬 개발 기준 기본 포트입니다. 값은 `infra/docker-compose.yml`, `.env.example`, 각 모듈 설정을 기준으로 합니다.

## 로컬 주소

| 서비스 | 주소 | 비고 |
| --- | --- | --- |
| Nginx Gateway | `http://localhost` | `/` -> Frontend, `/api/` -> Spring |
| Frontend | `http://localhost:5173` | Vite dev server |
| Spring API | `http://localhost:8080/api/v1` | health: `/api/v1/health` |
| FastAPI | `http://localhost:8001/ai/v1` | health: `/ai/v1/health` |
| MariaDB | `localhost:3307` | 로컬 MySQL 3306 충돌 방지 |
| Redis | `localhost:6379` | 세션/캐시/상태 |
| MinIO API | `http://localhost:9000` | 파일 저장소 API |
| MinIO Console | `http://localhost:9001` | 로컬 관리 콘솔 |
| ChromaDB | `http://localhost:8000` | heartbeat: `/api/v1/heartbeat` |

## Docker 내부 주소

컨테이너끼리 통신할 때는 `localhost` 대신 서비스명/alias를 사용합니다.

| 서비스 | 내부 호스트 | 포트 |
| --- | --- | ---: |
| MariaDB | `mariadb` | `3307` |
| Redis | `redis` | `6379` |
| MinIO | `minio` | `9000` |
| ChromaDB | `chromadb` | `8000` |
| FastAPI | `ai-server` | `8001` |
| Spring | `spring` | `8080` |

## Nginx 공개 원칙

| 경로 | 처리 |
| --- | --- |
| `/` | Frontend |
| `/api/` | Spring Boot |
| `/ai/` | 차단 |
| `/minio/` | 차단 |
| `/chroma/` | 차단 |

외부 공개는 Nginx 단일 진입점을 사용합니다. `8080`, `8001`, `3307`, `6379`, `9000`, `9001`, `8000`, `11434`는 외부에 직접 공개하지 않습니다.
