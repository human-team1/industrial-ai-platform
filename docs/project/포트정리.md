# 포트 정리

로컬 개발 기준으로 각 서버, DB, 스토리지, 캐시의 기본 포트를 정리한 문서다.

## 기본 원칙

- 가능한 한 호스트 포트와 컨테이너 내부 포트를 동일하게 맞춘다.
- 이미 동일한 서비스는 유지한다.
- MariaDB는 로컬 MySQL `3306` 충돌 방지를 위해 내부/외부 모두 `3307`을 사용한다.
- ChromaDB는 기존처럼 내부/외부 모두 `8000`을 유지한다.

## 서비스 포트 요약

| 구분 | 서비스 | 호스트 포트 | 내부 포트 | 기본 주소 | 비고 |
| --- | --- | ---: | ---: | --- | --- |
| Frontend | React + Vite | `5173` | - | `http://localhost:5173` | `npm run dev` 기준 |
| Backend | Spring Boot | `8080` | `8080` | `http://localhost:8080` | API prefix `/api/v1` |
| AI Server | FastAPI | `8001` | `8001` | `http://localhost:8001` | AI API prefix `/ai/v1` |
| DB | MariaDB | `3307` | `3307` | `localhost:3307` | 로컬 MySQL `3306` 충돌 방지 |
| Cache | Redis | `6379` | `6379` | `localhost:6379` | 세션/캐시/상태 저장 |
| Object Storage API | MinIO | `9000` | `9000` | `http://localhost:9000` | 파일 업로드/다운로드 API |
| Object Storage Console | MinIO Console | `9001` | `9001` | `http://localhost:9001` | 관리자 콘솔 |
| Vector DB | ChromaDB | `8000` | `8000` | `http://localhost:8000` | 문서 벡터 검색 |

## 서버별 상세

### Frontend

```powershell
cd frontend
npm run dev
```

- 기본 주소: `http://localhost:5173`

### Spring Boot Backend

```powershell
cd backend-spring
.\gradlew.bat bootRun --args="--spring.profiles.active=local"
```

- 기본 주소: `http://localhost:8080`
- 헬스체크: `http://localhost:8080/api/v1/health`
- API base: `http://localhost:8080/api/v1`

### FastAPI AI Server

```powershell
cd ai-server
uvicorn main:app --reload --host 0.0.0.0 --port 8001
```

- 기본 주소: `http://localhost:8001`
- 헬스체크: `http://localhost:8001/ai/v1/health`
- Swagger: `http://localhost:8001/docs`
- AI API base: `http://localhost:8001/ai/v1`

## Docker Compose 인프라 포트

현재 `infra/docker-compose.yml` 기준 외부 노출 포트는 아래와 같다.

| 서비스 | 컨테이너 이름 | 포트 매핑 | 용도 |
| --- | --- | --- | --- |
| MariaDB | `industrial-mariadb` | `3307:3307` | 메인 DB |
| Redis | `industrial-redis` | `6379:6379` | 캐시/세션/상태 |
| MinIO | `industrial-minio` | `9000:9000` | 오브젝트 스토리지 API |
| MinIO Console | `industrial-minio` | `9001:9001` | 오브젝트 스토리지 콘솔 |
| ChromaDB | `industrial-chroma` | `8000:8000` | 벡터 DB |

## Docker 내부 서비스 주소

컨테이너끼리 통신할 때는 `localhost` 대신 서비스명/alias를 사용한다.

| 서비스 | Docker 내부 호스트 | 내부 포트 |
| --- | --- | ---: |
| MariaDB | `mariadb` | `3307` |
| Redis | `redis` | `6379` |
| MinIO | `minio` | `9000` |
| ChromaDB | `chromadb` | `8000` |
| FastAPI | `ai-server` | `8001` |

## 내부 통신 예시

- Spring → MariaDB: `jdbc:mariadb://mariadb:3307/industrial_ai`
- Spring → FastAPI: `http://ai-server:8001`
- Spring → ChromaDB: `http://chromadb:8000`
- FastAPI → ChromaDB: `http://chromadb:8000`
- FastAPI → MinIO: `http://minio:9000`

## 환경변수 기준 포트

### Spring 로컬 실행 기준

```env
APP_PORT=8080
DB_HOST=localhost
DB_PORT=3307
DB_NAME=industrial_ai
DB_URL=jdbc:mariadb://localhost:3307/industrial_ai
REDIS_HOST=localhost
REDIS_PORT=6379
MINIO_ENDPOINT=http://localhost:9000
CHROMA_HOST=localhost
CHROMA_PORT=8000
AI_SERVER_BASE_URL=http://localhost:8001
```

### Docker 내부 통신 기준

```env
APP_PORT=8080
DB_HOST=mariadb
DB_PORT=3307
DB_URL=jdbc:mariadb://mariadb:3307/industrial_ai
REDIS_HOST=redis
REDIS_PORT=6379
MINIO_ENDPOINT=http://minio:9000
CHROMA_HOST=chromadb
CHROMA_PORT=8000
AI_SERVER_BASE_URL=http://ai-server:8001
```

## 주의사항

- 로컬 브라우저에서 MinIO에 접속할 때는 `http://localhost:9000`, `http://localhost:9001`을 사용한다.
- Docker 내부에서 MinIO에 접속할 때는 `http://minio:9000`을 사용한다.
- FastAPI는 프로젝트 기준 `8001`을 사용한다.
- ChromaDB는 프로젝트 기준 `8000`을 유지한다.
- 데이터 보호를 위해 로컬 재기동 시 `docker compose down -v`는 사용하지 않는다.
