# 디렉터리 구조

현재 저장소의 주요 디렉터리와 책임입니다.

```text
industrial-ai-platform/
  frontend/          React + Vite 클라이언트
  backend-spring/    Spring Boot 메인 API 서버
  ai-server/         FastAPI AI/RAG 서버
  infra/             Docker Compose, Nginx, MariaDB, 운영 스크립트
  docs/              프로젝트 문서
  .github/           GitHub Actions
```

## Frontend

```text
frontend/src/
  app/        앱 초기화, provider, router
  pages/      라우트 단위 페이지
  widgets/    여러 feature/entity를 조합한 화면 블록
  features/   사용자 행동/기능 단위 api/model/ui
  entities/   도메인 데이터 모델과 entity 단위 UI/로직
  shared/     API client, 공통 UI, hooks, lib, types
```

의존 방향은 `app -> pages -> widgets -> features -> entities -> shared` 기준으로 하위 계층만 참조합니다.

## Spring Backend

```text
backend-spring/src/main/java/com/example/factoryguard/
  common/        공통 응답, 예외, 유틸
  config/        security, web, persistence, client 설정
  domain/        chat, dashboard, document, file, inspection, model, operation, result, review, user 등 도메인
  application/
    port/        in/out port
    service/     유스케이스 구현
    dto/         command/result DTO
  adapter/
    in/web/      Controller, request/response, web mapper
    out/         persistence, fastapi, minio, redis adapter
```

Controller는 비즈니스 로직을 갖지 않고 UseCase 호출과 요청/응답 변환만 담당합니다.

## FastAPI AI Server

```text
ai-server/
  api/             FastAPI router, request/response schema
  application/     vision/RAG/document/model usecase
  domain/          domain model, port, rule
  infrastructure/  MinIO, ChromaDB, Redis, model/RAG 구현체
  container/       DI 조립
  config/          settings
  scripts/         seed/smoke/helper script
  tests/           pytest
```

Router에서 구현체를 직접 생성하지 않고 container를 통해 의존성을 주입합니다.

## Infra

```text
infra/
  docker-compose.yml          로컬 개발용 인프라
  docker-compose.prod.yml     fullstack/prod 검증용 compose
  nginx/                      gateway 설정과 TLS 안내
  mariadb/
    init/                     최신 베이스라인 스키마
    migrations/               변경 이력
    seed/                     반복 적용 가능한 샘플 데이터
    demo-data/                환경 의존 수동 데이터
  scripts/                    DB/MinIO/검증 스크립트
```
