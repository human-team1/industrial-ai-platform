# 테스트 실행 가이드

실행 모드는 두 가지만 구분합니다.

| 모드 | 사용 파일 | 실행 방식 | 용도 |
| --- | --- | --- | --- |
| 로컬 개발 | 각 모듈 `.env` + `infra/.env` | 인프라는 Docker, Spring/FastAPI/Frontend는 호스트 실행 | 일상 개발/디버깅 |
| 로컬 fullstack/prod 검증 | `infra/docker-compose.prod.yml` + `infra/.env.prod` | 전체 서비스를 Docker 실행 | 배포 전 smoke |

비밀번호, 토큰, 인증서, API Key는 문서에 적지 않고 `.env` 또는 배포 환경 변수로만 관리합니다.

## 1. 로컬 개발 실행

### 1.1 env 생성

```powershell
Copy-Item .\infra\.env.example .\infra\.env
Copy-Item .\backend-spring\.env.example .\backend-spring\.env
Copy-Item .\frontend\.env.example .\frontend\.env
Copy-Item .\ai-server\.env.example .\ai-server\.env
```

### 1.2 인프라 기동

```powershell
cd infra
docker compose --env-file .env up -d
docker compose --env-file .env ps
.\scripts\db-migrate.ps1
.\scripts\db-seed.ps1
.\scripts\init-minio-buckets.ps1
cd ..
```

DB를 완전히 재생성해도 되는 경우만 아래를 사용합니다.

```powershell
cd infra
.\scripts\db-reset.ps1 -Force
cd ..
```

### 1.3 애플리케이션 실행

Spring:

```powershell
cd backend-spring
.\gradlew.bat bootRun --args="--spring.profiles.active=local"
```

FastAPI:

```powershell
cd ai-server
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8001
```

Frontend:

```powershell
cd frontend
npm install
npm run dev
```

## 2. 로컬 fullstack/prod 검증

TLS 파일이 필요합니다. 로컬 self-signed 인증서는 [TLS 문서](../../infra/nginx/ssl/README.md)를 참고합니다.

```powershell
cd infra
Copy-Item .env.prod.example .env.prod
# .env.prod 값 채우기
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build
docker compose -f docker-compose.prod.yml --env-file .env.prod ps
```

접속:

- `https://localhost`
- `https://localhost/api/v1/health`

로컬 self-signed 인증서 경고는 정상입니다.

## 3. Smoke checklist

### 로컬 개발

- [ ] MariaDB, Redis, MinIO, ChromaDB 컨테이너 기동
- [ ] MinIO 필수 버킷 `documents`, `inspection-artifacts`, `reports`, `models` 존재
- [ ] Spring `http://localhost:8080/api/v1/health` 응답
- [ ] FastAPI `http://localhost:8001/ai/v1/health` 응답
- [ ] Frontend `http://localhost:5173` 접속
- [ ] 로그인/가입 승인 흐름 확인
- [ ] 이미지 업로드 검사 요청 후 결과 상태 전이 확인
- [ ] 문서 업로드 후 인덱싱/RAG 응답 확인

### 로컬 fullstack/prod 검증

- [ ] 전체 컨테이너 healthy
- [ ] `https://localhost` 접속
- [ ] `https://localhost/api/v1/health` 응답
- [ ] Google 로그인 설정 확인
- [ ] MinIO bucket 4종 존재
- [ ] 모델 아티팩트 seed 또는 활성 모델 배포 확인
- [ ] 업로드 검사와 결과 상세 확인
